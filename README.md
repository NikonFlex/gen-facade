# GenFacade

Генерация векторных чертежей фасадов зданий по текстовому описанию.

Выпускная квалификационная работа, Университет ИТМО.
Тема: «Разработка метода генерации векторных чертежей фасадов зданий».

```
вход:  текстовое описание фасада  (+ опционально форма здания)
выход: векторный фасад (SVG)
```

В отличие от растровой генерации, результат должен оставаться **чертежом**:
сохранять геометрическую структуру, повторяемость элементов и выравнивание,
и допускать последующее редактирование в векторном редакторе или CAD.

## Статус

Ранняя стадия: исследование предметной области и данных. Кода метода пока нет.

Что уже сделано:

- разобран датасет [CMP Facade](https://cmp.felk.cvut.cz/~tylecr1/facade/) —
  51 769 размеченных прямоугольников, измерена структурная регулярность фасадов
- изучена экосистема лаборатории CTLab-ITMO, определено, что переиспользуем
