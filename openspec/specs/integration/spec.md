# Стыковка с GenPlan и планами МКД

## Purpose
Тип: процесс. Как фасадный модуль встаёт в пайплайн лаборатории: после GenPlan отдельным
сервисом, без правок генерации GenPlan; окна обратно в 3D-конвертер GenPlan — позже, вместе с
Егором; планы многоквартирных домов — от коллег через свой адаптер. План объявляет спека
`plan-input`, лист фасадов — спека `facade`.

## Requirements

### Requirement: Отдельный сервис после GenPlan
Модуль MUST работать отдельным сервисом после GenPlan: принимать SVG-план и текст и отдавать лист
фасадов.

**Источник:** Чат 26–28.09 17 (стр. 137)

#### Scenario: Выход GenPlan
- GIVEN SVG-план, выданный GenPlan, и текст запроса
- WHEN модуль запускают на них без ручных правок SVG
- THEN он отдаёт лист фасадов

### Requirement: Генерацию GenPlan не меняем
Модуль MUST NOT требовать правок генерации планов в GenPlan: режим «глухой куб» делается в
препроцессоре модуля.

**Источник:** решение агента 28.09.2026 — заделывать в препроцессоре, генерацию GenPlan не менять

#### Scenario: Глухой режим на плане с окнами
- GIVEN план GenPlan с окнами
- WHEN модуль работает в режиме «глухой куб»
- THEN окна заделаны препроцессором, GenPlan запускается как есть

### Requirement: Окна в 3D-конвертер
Модуль MUST отдавать в JSON всё, что нужно 3D-конвертеру GenPlan вместо разрывов плана: сторону,
положение, ширину, низ и верх каждого проёма, этажность.

**Источник:** Чат 26–28.09 13 (стр. 125); Чат 26–28.09 24 (стр. 179)

#### Scenario: Окно в JSON
- GIVEN лист фасадов с окном 1,2 × 1,4 м с низом на 0,9 м
- WHEN 3D-конвертер читает JSON
- THEN у окна есть сторона, положение, ширина 1,2 м, низ 0,9 м и верх 2,3 м

### Requirement: Адаптер планов МКД
Модуль MUST принимать планы многоквартирных домов от коллег через свой адаптер во внутренний
План.

**Источник:** Чат 26–28.09 28 (стр. 199)

#### Scenario: План коллег
- GIVEN план многоквартирного дома в формате коллег
- WHEN адаптер его читает
- THEN получен План со сторонами и проёмами

### Requirement: Код GenPlan не копируем
Работа MUST NOT копировать код GenPlan без лицензии: он — внешний сервис и образец формата.

**Источник:** решение агента 28.09.2026 — код без лицензии не копируем

#### Scenario: Препроцессор
- GIVEN препроцессор модуля
- WHEN его сверяют с кодом GenPlan
- THEN скопированных фрагментов кода нет
