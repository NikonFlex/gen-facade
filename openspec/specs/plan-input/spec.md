# Вход: план дома и препроцессор

## Purpose
Тип: сущность. Во что превращается план этажа на входе, прежде чем по нему строить фасады
(шаг 2): стороны контура, проёмы, запретные зоны, метры. План приходит из разных систем
(GenPlan — коттеджи, коллеги — многоквартирные), поэтому внутри модуля он хранится в своём
формате. Запрос объявляет спека `task`, фасад стороны — спека `facade`.

## Сущности

### План

План одного этажа во внутреннем формате модуля: координаты — метры, ось y вверх.

| Поле | Значение | Источник |
|---|---|---|
| стены | осевые прямоугольники, как в источнике; перекрытия сливает препроцессор, в стенах они остаются | Чат 26–28.09 32 (стр. 225); решение агента 30.09.2026 — стены хранятся как в источнике |
| наружный контур | замкнутый многоугольник по часовой стрелке | решение агента 28.09.2026 — контур обходится по часовой стрелке |
| проёмы | все проёмы плана — Проём плана | Чат 26–28.09 32 (стр. 227) |
| стороны | стороны контура — Сторона; заполняет препроцессор | решение агента 28.09.2026 — фасад строится на сторону контура |
| масштаб | метры на пиксель источника — чтобы вернуться к координатам SVG | Чат 26–28.09 32 (стр. 230) |
| откуда | GenPlan, многоквартирный от коллег, синтетика, BuildingNet, BIO, ручная разметка | решение агента 01.10.2026 — источники планов совпадают с источниками данных |

Состояний нет.

## Requirements

### Requirement: Чтение плана GenPlan
Препроцессор MUST читать план GenPlan: SVG из осевых прямоугольников в пикселях — стены, окна
и двери; наружные стены не помечены, типов проёмов и комнат нет, этаж один.

**Источник:** Чат 26–28.09 32 (стр. 224–229); решение агента 30.09.2026 — классы по цвету и двери по дуге сверены с кодом GenPlan

#### Scenario: Простой дом GenPlan
- GIVEN SVG простого дома 10 × 5 м, нарисованный кодом GenPlan
- WHEN препроцессор читает план
- THEN найдены стены, окна и входная дверь этого SVG

### Requirement: Масштаб по ширине входа
Препроцессор MUST переводить пиксели плана в метры по ширине входной двери 0,9 м.

**Источник:** Чат 26–28.09 32 (стр. 230); решение агента 30.09.2026 — масштаб по ширине входа, как в 3D-конвертере GenPlan

#### Scenario: Вход 45 px
- GIVEN план, где входная дверь шириной 45 px
- WHEN препроцессор переводит план в метры
- THEN масштаб — 0,02 м на пиксель

### Requirement: Высоты не из плана
Препроцессор MUST NOT брать из плана этажность, высоты и крышу: их задают параметры дома из
текста.

**Источник:** Чат 26–28.09 32 (стр. 229)

#### Scenario: План без высот
- GIVEN план GenPlan, в котором есть только стены и проёмы
- WHEN препроцессор его разобрал
- THEN в плане нет этажности и высот, у сторон — только длина

### Requirement: Свой формат плана
Препроцессор MUST хранить план во внутреннем формате модуля: координаты в метрах, ось y вверх.

**Источник:** решение агента 30.09.2026 — свой формат плана, не привязанный к GenPlan

#### Scenario: Ось y
- GIVEN в SVG точка с y = 0 px у верхнего края холста
- WHEN препроцессор переводит план
- THEN в плане у этой точки наибольший y

### Requirement: Стороны и проёмы контура
Препроцессор MUST сливать перекрывающиеся стены, находить замкнутый наружный контур, резать его
на стороны и проецировать на каждую её проёмы.

**Источник:** ТЗ 7.4 (стр. 27); решение агента 28.09.2026 — препроцессор из шести шагов: слить, контур, стороны, проёмы, запретные зоны, метры

#### Scenario: Простой дом
- GIVEN SVG простого дома 10 × 5 м, нарисованный кодом GenPlan
- WHEN препроцессор его разобрал
- THEN контур замкнут, у него 4 стороны, найдены все проёмы SVG с точностью 2 px

### Requirement: Проём только по разрыву
Препроцессор MUST признавать проём, только если между двумя соосными стенами наружного контура
есть разрыв; прямоугольник окна или двери из SVG — лишь подсказка вида.

**Источник:** решение агента 30.09.2026 — проём только по разрыву, своим кодом вместо правила GenPlan

#### Scenario: Коробка без разрывов
- GIVEN план из четырёх стен без разрывов
- WHEN препроцессор ищет проёмы
- THEN проёмов нет, а план отклонён с причиной «нет входа»

### Requirement: Вид проёма по разрыву
Препроцессор MUST считать разрыв с дугой двери дверью, наружный разрыв без створки — окном,
внутренний без створки — проходом, а не проёмом.

**Источник:** решение агента 30.09.2026 — вид проёма по дуге створки

#### Scenario: Окно без створки
- GIVEN наружный разрыв шириной 1,2 м без дуги и створки
- WHEN препроцессор определяет вид проёма
- THEN это окно

### Requirement: Вход — самая узкая наружная дверь
Препроцессор MUST считать входом самую узкую наружную дверь, а если наружных дверей нет — самый
узкий наружный разрыв.

**Источник:** решение агента 30.09.2026 — вход по ширине, как у правила GenPlan

#### Scenario: Две наружные двери
- GIVEN две наружные двери шириной 0,9 м и 1,2 м
- WHEN препроцессор ищет вход
- THEN вход — дверь шириной 0,9 м

### Requirement: Соосные стены и швы
Препроцессор MUST считать соосными стены, перекрывающиеся не меньше чем на половину толщины, а
разрыв короче порога из настроек — швом векторизации, не проёмом.

**Источник:** решение агента 30.09.2026 — швы векторизации отсекаются порогом

#### Scenario: Шов
- GIVEN между двумя соосными стенами разрыв короче порога
- WHEN препроцессор ищет проёмы
- THEN стены слиты, проёма нет

### Requirement: Стена в полосе окна
Препроцессор MUST оставлять проём, в полосу которого лишь заходит внутренняя стена, и ставить
поверх него запретную зону.

**Источник:** Чат 26–28.09 21 (стр. 149); решение агента 30.09.2026 — проём остаётся, поверх — запретная зона

#### Scenario: Внутренняя стена у окна
- GIVEN внутренняя стена заходит в полосу наружного окна, но не перекрывает его на всю толщину
- WHEN препроцессор разбирает сторону
- THEN окно остаётся проёмом, поверх него — запретная зона

### Requirement: Запретная зона у внутренней стены
Препроцессор MUST отмечать запретную зону там, где к наружной стене примыкает внутренняя;
наружной считается только стена, вытянутая вдоль стороны.

**Источник:** решение агента 30.09.2026 — внутренние стены GenPlan прорисованы до наружной грани

#### Scenario: Перегородка
- GIVEN к стороне длиной 10 м примыкает внутренняя стена на отметке 4 м
- WHEN препроцессор разбирает сторону
- THEN на стороне запретная зона вокруг отметки 4 м

### Requirement: Глухой режим заделывает разрывы
Препроцессор MUST в режиме «глухой куб» заделывать наружные разрывы, кроме входа: стены по обе
стороны сливаются.

**Источник:** Чат 26–28.09 17 (стр. 137); решение агента 28.09.2026 — заделывать в препроцессоре, генерацию GenPlan не менять

#### Scenario: Простой дом в глухом режиме
- GIVEN простой дом 10 × 5 м с окнами и входом
- WHEN препроцессор разбирает его в режиме «глухой куб»
- THEN у плана ровно один наружный проём — вход

### Requirement: Отказ на дефектном плане
Препроцессор MUST отказывать с причиной, если контур не замкнулся, стены не связаны или нет
входа, и не чинить план молча.

**Источник:** решение агента 28.09.2026 — дефектный план отклоняется с причиной

#### Scenario: Нет входа
- GIVEN план без наружной двери и без наружных разрывов
- WHEN препроцессор его разбирает
- THEN отказ с причиной «нет входа»
