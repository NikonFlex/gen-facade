# И-01. Сбор данных для обучения и теста

Роль: исследователь. Релиз: входит.

## Начальное состояние

Корень данных задан в настройках и лежит на отдельной машине; данных в репозитории нет.

## Шаги

1. Исследователь собирает синтетику первой ступени: 100 прямоугольных домов. Ожидаемо: 100
   примеров «план + все фасады» в 1–3 этажа с окнами на каждом этаже и опись с долей глухих стен;
   повторный запуск продолжает сборку.
   Требования: `data: Синтетика своим генератором`, `data: Глухие стены в синтетике`,
   `data: Этажность синтетики`,
   `data: Сборка синтетики по seed`, `data: Сборка не смешивает настройки`,
   `data: Хранение примеров`, `data: Данные вне git`, `data: Ступени данных`
2. Исследователь извлекает коттеджи из BuildingNet. Ожидаемо: примеры с планом и фасадами в
   метрах, выше карниза ничего нет, модели BuildingNet не публикуются; SYNBUILD-3D не берётся.
   Требования: `data: Коттеджи из BuildingNet`, `data: Извлечение BuildingNet`,
   `data: BuildingNet только некоммерчески`, `data: Стена до карниза в данных`,
   `data: Без SYNBUILD-3D`
3. Исследователь размечает реальные коттеджи и рендеры Егора. Ожидаемо: тест только из реальных
   домов, каждый дом — в одной части.
   Требования: `data: Реальные коттеджи — тест`, `data: Тест — только реальные данные`,
   `data: Разбиение без утечек`, `data: Данные лаборатории`
4. Исследователь переводит CMP и другие фасады многоквартирных. Ожидаемо: примеры без плана, CMP
   туда и обратно без потерь, структура датасетов описана.
   Требования: `data: Многоквартирные из открытых датасетов`, `data: CMP без плана`,
   `data: Исследование датасетов`, `facade: Разметка CMP без потерь`
5. Исследователь синтезирует описания. Ожидаемо: шаблонные, перефразированные и ручные описания;
   парсер на эталоне выполняет 100% требований.
   Требования: `data: Описания из разметки`
