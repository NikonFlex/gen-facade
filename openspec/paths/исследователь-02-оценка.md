# И-02. Обучение, метрики и сравнение

Роль: исследователь. Релиз: входит.

## Начальное состояние

Данные собраны по пути И-01; тест — реальные дома.

## Шаги

1. Исследователь обучает кандидатов архитектуры, сначала в режиме «окна из плана». Ожидаемо:
   модели на PyTorch, среди них трансформер и графовая.
   Требования: `generation: Сначала режим окон из плана`, `generation: Кандидаты архитектуры`,
   `task: Стек`
2. Исследователь считает метрики одной командой. Ожидаемо: таблица пяти групп ТЗ и двух своих на
   реальном тесте, BuildingNet — отдельной колонкой, SVD — вспомогательной.
   Требования: `evaluation: Метрики одной командой`, `evaluation: Пять групп метрик`,
   `evaluation: Согласованность с планом`, `evaluation: Соответствие описанию`,
   `evaluation: SVD-метрика — вспомогательная`, `evaluation: Основная таблица на реальном тесте`,
   `evaluation: Калибровка допусков`
3. Исследователь считает свод правил фасада. Ожидаемо: у каждого правила — источник и число домов
   реального теста, которые его выполняют; лист с нарушением правила не бракуется.
   Требования: `evaluation: Свод правил фасада`
4. Исследователь сравнивает метод с базовыми подходами. Ожидаемо: строки правила GenPlan, LLM без
   дообучения, растра + EvoVec, building_tools.
   Требования: `evaluation: Базовые подходы`, `generation: Растр и EvoVec — базовый подход`
5. Исследователь проводит ablation. Ожидаемо: таблица ablation по шести вариантам.
   Требования: `evaluation: Ablation`
6. Исследователь готовит материалы защиты. Ожидаемо: обзор литературы в тексте ВКР, лист
   открывается в CAD через DXF, код GenPlan в работе не скопирован.
   Требования: `task: Обзор литературы`, `facade: CAD через экспорт`,
   `integration: Код GenPlan не копируем`
