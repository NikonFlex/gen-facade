## Правила

1. Модуль — отдельный сервис после GenPlan: принимает SVG-план и текст,
   отдаёт `FacadeSheet` *(Егор 28.09)*.
2. Генерацию планов в GenPlan не меняем; режим без референсов делается
   в препроцессоре модуля (plan-input.md, правило 6). `DECISION 2026-09-28`,
   ждёт ответа Егора (docs/decisions.md).
3. Обратная связь в 3D — позже и вместе с Егором: 3D-конвертер GenPlan
   (`create_3d`) должен принимать окна из `FacadeSheet` с высотами каждого окна
   и этажностью вместо разрывов плана и одной высоты от BART.
4. Планы МКД приходят от других коллег *(Валерия 28.09)*; для них пишется
   свой адаптер во внутренний `Plan`.
5. Код GenPlan без лицензии: используем как внешний сервис и как образец формата,
   код не копируем (docs/lab-repos.md, сводка по лицензиям).

## Критерии приёмки

- Модуль запускается на выходе GenPlan без ручных правок SVG.
- JSON из `FacadeSheet` содержит всё, что нужно конвертеру по п. 3: сторона,
  положение, ширина, низ и верх каждого проёма, этажность.
