# Спеки

Замысел работы: что строим, из чего, как проверяем. **Единственный источник
требований** — код и эксперименты делаются по этим файлам. Входящие документы
(`docs/incoming/`) — сырьё, не требования. Порядок работы — [docs/SPEC-DRIVEN.md](../docs/SPEC-DRIVEN.md).

Всё, что не подтверждено хозяином или научруком, — `provisional`. Подтверждённый
пункт помечается датой и именем: *(подтвердила Валерия 28.09)*.
Решение агента без подтверждения — `DECISION <дата>`.
