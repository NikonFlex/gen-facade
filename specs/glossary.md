## Термины

| Термин | Значение | Не путать с |
|---|---|---|
| **план** | план одного этажа дома на входе модуля: стены, окна, двери в векторе | «архитектурный план здания» из цели ТЗ — там имеется в виду проект целиком |
| **фасад** (facade, elevation) | ортогональная проекция одной наружной стороны дома со всеми элементами | фото фасада; перспектива |
| **сторона** | участок наружного контура плана, которому соответствует один фасад | стена (прямоугольник на плане) |
| **четыре фасада** | фасады всех сторон одного дома; для непрямоугольного контура сторон больше, «четыре» — обиходное название | — |
| **проём** (opening) | окно или дверь; на плане GenPlan — разрыв между соосными стенами | элемент фасада «окно» — у него есть ещё высота и подоконник |
| **режим с референсами** | проёмы заданы планом, модуль достраивает остальное | — |
| **режим без референсов** | на плане глухой объём (есть только входная дверь), проёмы ставит модуль | — |
| **спецификация дома** (HouseSpec) | параметры, общие для всех сторон: этажность, высоты, крыша, материалы | текстовое описание |
| **запретная зона** | участок стороны, где к наружной стене примыкает внутренняя; окно туда ставить нельзя | — |
| **коттедж** | отдельно стоящий частный дом, ИЖС (индивидуальное жилищное строительство) | — |
| **МКД** | многоквартирный дом | — |
| **лист фасадов** | SVG со всеми фасадами дома, подписями осей и отметками уровней, как в эскизном проекте | — |
| **отметка уровня** | высота характерной линии (пол, карниз, конёк) над нулём | — |
| **регулярность** | выравнивание элементов по этажам и вертикальным осям, постоянство шага | одинаковый размер всех окон |
| **GenPlan** | пайплайн лаборатории: текст → план → 3D (CTLab-ITMO/GenPlan) | GenPlan3D — название проекта в питче |
| **Facades-3D** | пайплайн лаборатории: процедурная структура городского фасада → растр → 3D | — |
