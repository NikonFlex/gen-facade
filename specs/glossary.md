## Термины

| Термин | Значение | Не путать с |
|---|---|---|
| **план** | план одного этажа дома на входе модуля: стены, окна, двери в векторе | «архитектурный план здания» из цели ТЗ — там имеется в виду проект целиком |
| **фасад** (facade, elevation) | ортогональная проекция одной наружной стороны дома со всеми элементами | фото фасада; перспектива |
| **сторона** | участок наружного контура плана, которому соответствует один фасад | стена (прямоугольник на плане) |
| **четыре фасада** | фасады всех сторон одного дома; для непрямоугольного контура сторон больше, «четыре» — обиходное название; в спеках — «все фасады» | — |
| **проём** (opening) | окно или дверь; на плане GenPlan — разрыв между соосными стенами | элемент фасада «окно» — у него есть ещё высота и подоконник |
| **режим 1 · глухой куб** (режим без референсов, `blind`) | на плане глухой объём (есть только входная дверь), проёмы ставит модель | — |
| **режим 2 · окна из плана** (режим с референсами, `with_openings`) | проёмы заданы планом, модель достраивает высоты, зоны отделки, декор | — |
| **параметры дома** (спецификация дома, HouseSpec) | общие для всех сторон: тип, этажность, высоты, цоколь, карниз, крыша, стиль, палитра; результат шага 1 | текстовое описание |
| **палитра дома** | набор материалов и цветов дома (штукатурка, дерево, камень, металл…); зоны и элементы ссылаются на неё | библиотека материалов — всё, из чего палитра выбирается |
| **зона отделки** (MaterialZone) | участок стены одного материала: цоколь, основная отделка, акцент, пояс | элемент (окно, дверь) |
| **уровни состава фасада** | 1 — проёмы с типом и делением рам; 2 — зоны отделки, цоколь, подоконники, наличники, карниз, пояса; 3 — крыльцо, козырёк, балкон, терраса, навес (позже) | — |
| **деление рамы** | как окно разбито на створки и импосты — часть `variant` проёма | тип проёма (обычное, панорамное…) |
| **развёртка** | силуэты всех стен дома (шаг 3): прямоугольник стены + фронтон или скат, из параметров дома и длины стороны | лист фасадов — развёртка с элементами и отделкой |
| **привязка к сетке** | выравнивание элементов по линиям этажей и вертикальным осям после генерации (шаг 5) | квантование координат модели |
| **цоколь** | нижняя полоса стены над землёй другого материала; высота — из параметров дома | — |
| **карниз** | линия и выступ по верху стены под крышей; отметка — из параметров дома | — |
| **запретная зона** | участок стороны, где к наружной стене примыкает внутренняя; окно туда ставить нельзя | — |
| **коттедж** | отдельно стоящий частный дом, ИЖС (индивидуальное жилищное строительство) | — |
| **МКД** | многоквартирный дом | — |
| **лист фасадов** | SVG со всеми фасадами дома, подписями осей и отметками уровней, как в эскизном проекте | — |
| **отметка уровня** | высота характерной линии (пол, карниз, конёк) над нулём | — |
| **регулярность** | выравнивание элементов по этажам и вертикальным осям, постоянство шага | одинаковый размер всех окон |
| **GenPlan** | пайплайн лаборатории: текст → план → 3D (CTLab-ITMO/GenPlan) | GenPlan3D — название проекта в питче |
| **Facades-3D** | пайплайн лаборатории: процедурная структура городского фасада → растр → 3D | — |
