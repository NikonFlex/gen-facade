Модуль, который по векторному плану дома и текстовому описанию строит все фасады
дома как векторный чертёж в цвете. Встаёт после GenPlan. Тема ВКР —
«Разработка метода генерации векторных чертежей фасадов зданий» (ТЗ).

## Сущности

### Request

Один запрос к модулю.

| Поле | Значение |
|---|---|
| `text` | текстовое описание дома на естественном языке; в нём же тип дома |
| `plan` | векторный план этажа — `Plan` (plan-input.md) |
| `mode` | `with_openings` \| `blind` — режим с референсами / без референсов |
| `seed` | для воспроизводимости |

Результат запроса — `FacadeSheet` (facade.md).

## Правила

1. Вход — текст **и** векторный план *(подтвердила Валерия 28.09)*.
2. Выход — все фасады дома, векторный чертёж, в цвете *(Валерия 28.09)*.
3. Типы домов — коттеджи и многоквартирные; тип задаётся в тексте, модель одна
   *(Валерия 28.09: «скорее с выбором по тексту»)*.
4. Два режима: без референсов (глухой объём) и с референсами (заданы окна и двери)
   *(Егор 28.09)*.
5. Коттеджи — основной тип для встраивания в GenPlan *(Егор 28.09)*; многоквартирные
   нужны к отчёту «в конце года» *(Валерия 28.09)*.
6. ГОСТы соблюдать не требуется *(Егор 28.09)*.
7. Вне работы на текущем этапе, возвращаемся после фасадов: разрезы, 3D-модель
   и BIM, фотореалистичные текстуры *(хозяин 28.09)*. 3D-модель делается позже
   совместно с Егором *(Валерия 28.09)*.
8. Стек — Python + PyTorch (ТЗ, «Требования»).

## Критерии приёмки

- На любом плане GenPlan из тестового набора модуль в обоих режимах выдаёт
  `FacadeSheet`, который проходит валидатор (evaluation.md) без нарушений
  класса «ошибка».
- Для каждой из пяти групп метрик ТЗ есть посчитанное число на тестовом наборе
  для метода и для каждого базового подхода.
- Тип дома из текста (коттедж / МКД) меняет результат: на одном плане
  с разным типом в тексте получаются разные фасады.
