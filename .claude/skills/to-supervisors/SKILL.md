Сообщение научрукам — обещание наружу, поэтому каждый шаг — по слову хозяина (хозяин 08.10).
Без его просьбы вопросы не готовить и в Telegram не слать: `/inbox` только отмечает «стоит
спросить: …».

## 1. Собрать — когда хозяин сказал «пишем научрукам»

Кандидаты, у каждого — откуда взят:
- что назвал сам хозяин;
- «## Открыто» в `specs/*.md`, кроме уже помеченного «спросили <дата>»;
- «стоит спросить» из последних разборов `/inbox` (низ задачи, история чата).

Показать список и спросить, что берём. Не выбирать за хозяина.

## 2. Доделать вместе

Черновик одним сообщением, простым текстом, как пишет хозяин: по-русски, без разметки,
обращение по именам, вопросы нумерованы. Кому каждый вопрос: Валерия — тема, ТЗ и защита;
Егор — GenPlan и пайплайн (правило 4 CLAUDE.md). Правки — по словам хозяина, сколько
понадобится кругов. Готово — только когда хозяин так сказал.

## 3. Отправить — только по «отправь»

Текст — файл в scratchpad, затем
`python3 tools/tg_inbox.py send --topic questions --file <файл>`. Бот пишет только в группу
хозяина: в чат научрукам хозяин копирует сам.

## 4. После

Когда хозяин скажет, что отправил научрукам, — в «Открыто» нужной спеки у вопроса пометка
«спросили <дата>». Ответы придут пересылкой через `/inbox`.
