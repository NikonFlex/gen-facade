# GenPlan: формат плана и 3D-конвертер

Проверенные факты о чужой системе, в которую встраивается модуль. Норма — спеки `plan-input` и
`integration`; здесь — на чём они стоят. Перенесено из прежней `specs/plan-input.md` (gf#14,
gf#34, gf#36) при переходе на OpenSpec 13.10.2026 (gf#116).
