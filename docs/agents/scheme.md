# Схема пайплайна — подробно

Прочитать до правки кода, спек и тестов (Claude Code и Cursor подгружают сами). Скелет схемы,
роли и главная идея — в `AGENTS.md`, «Схема»; картинка — `docs/assets/facade-modules.png` (исходник `.svg`
рядом), согласована с хозяином 28–29.09; Егор 29.09 — суть верная, просил упростить и выделить
входы и выходы (оригинал — `docs/incoming/Переписка в Telegram 29.09–06.10.md`). Режимы выделены цветом:
режим 1 — синий, режим 2 — фиолетовый. Пример на картинке — одноэтажный дом, для простоты
(решение хозяина 28.09). Схема поменялась — перерисовать картинку, поправить этот блок,
скелет в `AGENTS.md` и спеки в тот же заход.

```
Вход: текст описания — идёт и в GenPlan, и в фасадный модуль.

ЕГОР · GenPlan
  текст → GenPlan (SDXL + white loss → векторизация → проёмы из разрывов)
        → SVG-план (стены с разрывами под окна и двери)
  SVG-план → 3D-конвертер GenPlan → 3D-модель   [работает сейчас: окна из разрывов плана]
  3D-модель с нашими окнами                    [позже, делаем ВМЕСТЕ]

НИКОН · фасадный модуль — 7 шагов: модель на шагах 1 и 4, остальное код
РЕЖИМ 1 · ГЛУХОЙ КУБ — окна ставит модель (шаг 1 общий для обоих режимов)
  1. текст → параметры дома (тип, этажи, высота, крыша, стиль, палитра,
     вид подоконника, наличника, ставен, козырька) — одни на все стены  [модель]
  2. SVG-план → препроцессор: стороны, заделанные разрывы
     (глухой режим, кроме входа), запретные зоны, метры      [код]
  3. развёртка: прямоугольник каждой стены — длина из плана,
     высота до карниза; крыши ещё нет                       [код]
  4. модель раскладывает каждую стену: проёмы с типом и делением рам
     (окно — один из 1–3 типоразмеров дома), зоны отделки из палитры дома,
     цоколь, карниз, пояса (высоты цоколя и карниза — из параметров дома);
     подоконник, наличник, ставни, козырёк — признаком у проёма, прямоугольник
     ставит код по виду дома (gf#212); крыльцо — уровень 3, позже;
     вход: стена + запретные зоны + параметры + текст        [модель]
     (с референсами окна по горизонтали уже заданы планом)
  5. привязка к сетке этажей и осей + валидатор;
     не прошло → генерируем заново                           [код]
  6. лист фасадов: цвета из параметров дома, отметки уровней и оси
     (оформление — только здесь), SVG + JSON; крыша пока плоская  [код]
  7. окна из фасадов → 3D-конвертер GenPlan                  [позже, вместе с Егором]
ОБУЧЕНИЕ И ОЦЕНКА (нижняя полоса схемы; данных на схеме нет — они
  отправляются научрукам текстом, состав — спека `data`)
  обучение модели для шагов 1 и 4 (сначала синтетика, потом реальные дома)
  → метрики на реальных домах (визуальное сходство, геометрия, структура,
  разнообразие, валидные SVG, согласованность с планом и с описанием)
  → сравнение с правилом GenPlan, LLM без дообучения, растр + EvoVec,
  building_tools со случайными параметрами; ablation

РЕЖИМ 2 · ОКНА ИЗ ПЛАНА — окна заданы планом, модель достраивает остальное;
  меняются шаги 2–5, шаг 1 и лист те же
  2. окна берём из плана (не заделываем) и раскладываем по сторонам;
     на схеме окна стоят нормально (решение хозяина 28.09) — что делать
     с окном, в которое упирается внутренняя стена, — вопрос в openspec/README.md
  3. на развёртке отмечены положения окон по горизонтали
  4. модель достраивает: x и ширина из плана; высота и декор — её
  5. валидатор дополнительно: окна стоят там же, где на плане

КОЛЛЕГИ
  планы многоквартирных (формат уточняется) → шаг 2
```
