# Таблица требований

Статус каждого требования из `openspec/specs/` — ровно одной строкой. Сводку и статусы из
записей прогона (`openspec/runs/`) переносит `python3 tools/req_status.py --write`; без флага
программа только показывает расхождения. Чтение кода ✅ не даёт.

| Статус | Значение | Чем подтверждается |
|---|---|---|
| ✅ | сделано и проверено на рабочем контуре | испытание, демонстрация или анализ |
| 🟡 | сделано частично, остаток записан | проверка на контуре либо чтение кода, нашедшее, чего нет; остаток — в строке и в задаче |
| 🚚 | код выложен, на контуре не проверено | чтение кода, тест в репозитории |
| 🔁 | сделано иначе, чем в источнике, по решению инженера | строка «Решения инженера» |
| ❌ | нет | — |
| ⚪ | не сверено | — |

Таблица пересверяется после каждой волны выкладки на рабочий контур; у диплома контура нет —
после слияния задачи, по прогону `genfacade run` и смотрелке (`docs/shared/SDD.md`, «Диплом»).
