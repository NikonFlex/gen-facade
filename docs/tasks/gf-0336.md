## Описание из трекера

Хозяин 07.11: «А крыши и карнизы размечать не будем?» — «Как считаешь нужным». Замер 07.11: у
37 домов реального теста (`data/samples/manual/`) крыша в параметрах дома — плоская у всех
[проверено: `spec.roof.kind` примеров — flat × 37]: сборщик ставит `Roof(kind=FLAT)`
(`genfacade/datasets/manual.py`, `house`), а вид, уклон и свес записаны только текстом в поле
`roof` разметки — в опись. С gf#320 вид крыши — условие модели шага 4 (`train/tokens.py`), и от
него зависит, на каких стенах карниз (`facade: Карниз под скатом`): в реальном тесте модель
получает неверное условие почти у всех домов (плоских из 27 американских — 6, у российских — ни
одной), реальный тест gf#328 (run 42381524429) посчитан с этой ошибкой.

Что сделать:
- разметка: поля `roof_kind` (вид из `RoofKind`), `pitch_deg`, `overhang_m` у всех 37 домов —
  по тексту поля `roof` и отметкам листа (конёк, свес); вид, которого модуль не строит (гамбрел,
  бабочка, составная), — ближайший строящийся, строка описи с причиной;
- сборщик: крыша дома — из этих полей; конёк по правилу модуля (у двускатной — вдоль длинных
  стен) — сверить с листом, дом с коньком поперёк — строка описи;
- прежние разметки собираются; поменялись только крыша и карниз на щипцовых стенах;
- реальный тест заново на GPU (`gpu.yml`, задача `realtest`), таблица против прежней (run
  42381524429), отдельно по российским домам.

Требования: `openspec/specs/data/spec.md` — «Разметка — запись чертежа целиком», «Реальные коттеджи — тест»; `openspec/specs/facade/spec.md` — «Карниз под скатом»

Готово, когда:
- у всех 37 домов теста вид крыши в параметрах дома — из разметки: распределение видов — в файле
  задачи, плоских — столько, сколько плоских на листах; тест сборщика: двускатная разметка даёт
  двускатную крышу и стены без карниза под щипцом — падает на нынешнем коде;
- `genfacade manual` — ошибок валидатора 0, опись расхождений (вид не строится, конёк поперёк)
  — в файле задачи;
- реальный тест на GPU с новой крышей — таблица рядом с прежней в файле задачи;
- хозяин посмотрел листы нескольких реальных домов со скатной крышей в смотрелке.

Датчик: доля домов реального теста, у которых вид крыши в параметрах совпадает с листом.
