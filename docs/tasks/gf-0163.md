## Описание из трекера

ТЗ требует ablation. Часть строк считается без нового обучения — на ответах той же модели:

- без запрета против с запретом — числа есть (gf#148, `docs/metrics-results.md`);
- без привязки к сетке (шаг 5) — листы до привязки: `genfacade eval` выгружает после привязки,
  нужна выгрузка «до»;
- общие параметры дома против независимых сторон — каждая стена отвечается моделью отдельно, со
  своими параметрами из того же распределения: что ломается на углах (`plan`/`corner`) и в описании;
- с обучением, позже — свой формат против сырого SVG текстом, предобучение на синтетике,
  архитектуры (gf#10): записать план и стоимость, не делать без «обучай».
