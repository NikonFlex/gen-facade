## Описание из трекера

Из `docs/dev-plan.md`, раздел «Трасса и смотрелка». Конвейер сохраняет выход каждого шага в `outputs/runs/<id>/` (JSON и SVG, отрисованный модулем `render/`); веб-страница (FastAPI + одна HTML-страница) показывает шаги по порядку, слои, сведения об элементе при наведении, сравнение двух прогонов, галерею. Сама ничего не считает.

Версии: v0 в конце этапа 0 — выбрать тестовый дом, увидеть силуэты и лист; этап 1 — все шаги, загрузка SVG GenPlan, слои, нарушения; потом галерея датасетов и сравнение. Редактор плана — отдельной задачей после этапа 1.

**Готово, когда (v0):** `genfacade serve` поднимает страницу; на ней выбирается тестовый дом, запускается прогон, видны силуэты стен и лист фасадов; прошлые прогоны открываются без пересчёта; тест, что сервер отдаёт трассу.

## Что установлено

Смотрелка v0 сделана 29.09 `[проверено: 55 passed, скриншоты глазами, CI]` — PR #48.

**Выбор (правило 1):** FastAPI 0.142 + uvicorn 0.54 (группа `[viewer]`) и одна страница
на обычном JS — без сборки и CDN, работает офлайн. NiceGUI живой (3.17), но наведение
на элементы SVG, слои и зум удобнее в браузере напрямую; Streamlit под интерактивный
SVG не подходит. Тестовый клиент — `httpx2` (starlette считает `httpx` устаревшим).

- **Трасса** — `genfacade/pipeline.py`: `input.json`, `03_unfold.svg` (стены без
  элементов), `06_sheet.svg`, `sheet.json`, `preview.png`, `meta.json` со списком
  шагов 1–6 (`file = null` у ещё не написанных). `genfacade render` идёт через него же.
- **Сервер** — `genfacade/viewer/app.py`: `/api/houses`, `/api/runs` (список, запуск
  дома или присланного JSON), `/api/runs/{id}`, файлы трассы `/files/…`. Имя прогона
  проверяется регуляркой — за пределы `runs_dir` не выйти (тест).
- **Страница** — `viewer/static/`: дома с палитрой и габаритами, свой JSON перетаскиванием,
  история с миниатюрами; шаги 1–6 (неготовые — пунктиром с подсказкой); чертёж
  в shadow DOM (CSS листа не смешивается со страницей): масштаб колесом к курсору,
  сдвиг, слои (зоны, элементы, створки, крыша, подписи), карточка элемента при наведении;
  шаг «Вход» — редактор JSON + сводка дома, «Прогнать» создаёт новый прогон,
  ошибки схемы — под редактором по-русски; тема светлая / тёмная / как в системе;
  клавиши ←/→, F, +/−; состояние в адресе (`#run=…&step=…`).
- **Настройки** — `config/viewer.toml`: адрес, порт, `runs_dir`, `houses_dirs`.

**Проверено глазами (скриншоты Playwright):** пустой экран, лист, масштаб 246 %,
наведение (карточка двери), развёртка, вход, ошибка схемы, тёмная тема, узкий экран 820 px.

всплывашкой; «Value error,» от pydantic в тексте.

**jscpd теперь смотрит и JS/CSS** — сразу нашёл дубль блока тёмной темы (для системной

## Два экрана вместо боковой панели, 30.09 `[проверено: скриншоты, переходы Playwright, 55 passed]`

Хозяин: панель домов и прогонов занимает много места, прогон должен быть на весь экран.
- **Главная** — дома карточками + «свой дом», прогоны сеткой с крупными миниатюрами.
- **Прогон** — на всю ширину; «← Все прогоны», название, дата, коммит, SVG/JSON/PNG
  и «Прогнать заново» — в верхней полосе; под ней только шаги и чертёж.
- Переходы: открытие прогона с главной — запись в истории браузера (`pushState`),
  шаги и перезапуск — замена; Esc, «← Все прогоны», логотип, «назад» в браузере —
  на главную; адрес с шагом переживает перезагрузку. Проверено сценарием из 8 переходов.
- Узкий экран: чипы прячутся, у «Прогнать заново» остаётся иконка, SVG/JSON/PNG — с подписями.

## Кэш браузера и гонка при переходах, 30.09 `[проверено: 21 из 21 по публичному адресу, браузер с кэшем]`

Хозяин открыл обновлённую смотрелку: главная без сетки, кнопки не работают. Причина —
**браузер взял из кэша старые `app.js` и `style.css` к новому `index.html`**: сервер не
отдавал `Cache-Control`, Chrome кэширует такие файлы по своей эвристике. Playwright
у меня каждый раз стартовал с пустым кэшем, поэтому проблему не видел.
- Middleware: страница и статика — `Cache-Control: no-cache` (перепроверка, 304 при
  неизменном файле); файлы прогонов `/files/…` не меняются — их не трогаем. Тест
  `test_page_and_static_revalidated`, проверен поломкой.
- Проверено в браузере с постоянным профилем: после правки `app.js` обычный переход
  отдаёт новую версию. **Старый кэш у хозяина это не сбросит — один раз Cmd+Shift+R.**
- Сквозная проверка всех кнопок по http://31.59.120.5:8000 (скрипт Playwright, 21 пункт:
  дома, масштаб, слои, наведение, ссылки SVG/JSON/PNG, шаги, редактор с ошибкой
  и без, «Прогнать заново», Esc, «← Все прогоны», логотип, свой JSON, тема).
  Нашла гонку: уход на главную, пока грузится прогон, — загрузка открывала прогон
  поверх главной. Счётчик переходов `state.nav`: устаревшая загрузка ничего не рисует.
