## Что установлено

Проверено 01.10 запуском: `ruff check .` — чисто; `pytest` — 110 прошло; jscpd — 0 клонов;
`tools/spec_check.py` — «спеки в порядке»; `backlog.py --selftest` — пройдена.

**Enum.** Строками были одиннадцать закрытых наборов; теперь:

| Enum | Где | Что было |
|---|---|---|
| `Mode`, `ElementClass` | `schema.py` | `Literal[...]`-алиасы |
| `BuildingType`, `RoofKind`, `OpeningKind`, `PlanSource`, `VariantKind`, `FixedField`, `ZoneRole`, `Severity` | `schema.py` | `Literal[...]` в полях; вид проёма был записан дважды (`Opening`, `PlanOpening`) |
| `Rule` | `schema.py` | `Violation.rule: str`, имена правил строками в `validate.py` |
| `Axis` | `plan/gaps.py` | `X, Y = 0, 1` и `1 - axis` |
| `Mark` | `render/plan_svg.py` | классы `plan-*` строками в пяти местах |

- `Found.kind: str  # window | door | entrance` → `OpeningKind`; `config.Library.class_fill` —
  `dict[ElementClass, str]`: опечатка в классе элемента в `library.toml` теперь ошибка загрузки.
- CLI: `-m` разбирается в `Mode`, список допустимых — из enum.
- Все enum, уходящие в JSON и SVG, — `StrEnum`: записывается то же значение. Трасса простого
  дома в обоих режимах (`01_spec.json` … `06_sheet.svg`, `sheet.json`, `violations.json`,
  `request.json`) до и после — **байт в байт** (`cmp`); `meta.json` совпадает без даты.
  Картинки поэтому глазами не пересматривал.
- Правило — CLAUDE.md, «Код»; проверка — `tests/unit/test_code_rules.py::test_closed_sets_are_enums`:
  `Literal` со строками и сравнение со значением enum строкой в пакете. Тест проверен на сломанном
  коде: подложил `Literal["a", "b"]`, `e.cls == "window"` и `x in ("door", 1)` — все три пойманы.
  Заодно перепроверен тест на сокращения импорта (`import json as j` — пойман).
- Чего тест не видит: строку, переданную аргументом (`preprocess(svg, "blind", …)`), — а после
  перехода на `is` такая строка молча даёт режим 2. Так и нашлись два упавших теста. Вызовы —
  только с `Mode.…`.
