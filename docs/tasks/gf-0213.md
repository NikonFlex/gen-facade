## Описание из трекера

Страж (gf#132, gf#177, gf#197) запрещает токены, ломающие геометрию, но об архитектуре не знает;
при браке весь дом генерируется заново с новым seed, тем же промптом, до 5 попыток — причина
брака уходит только в трассу. Сходимости к правдоподобному дому нет: первый годный ответ
принимается, каким бы он ни был.

Что сделать:
- правила из свода правил фасада (gf#209) — в страж: размеры окна — только из типоразмеров дома, верх
  окон этажа — на общей линии, отступ от угла и простенок — не меньше нормы;
- лучший из N: N ответов, выбирается лучший по метрике правдоподобия (gf#210); N — настройка;
- перегенерация одной стены: префикс до плохой стены сохраняется, досэмплируется только она;
- строки ablation: без обратной связи, правила в страже, лучший из N, одна стена;
- позже, если хватит времени: дообучение на годных ответах (ReST-EM, Singh 2023).

`openspec/specs/generation/spec.md` — «Брак — заново»
`openspec/specs/evaluation/spec.md` — «Ablation»

**Готово, когда:**
- тест на каждое правило стража — красный без него;
- тест: перегенерация стены оставляет остальные стены дома без изменений;
- на реальном тесте метрика правдоподобия растёт с N (1, 4, 16) — числа в `docs/metrics-results.md`;
- строки ablation посчитаны в обоих режимах.

Датчик: метрика правдоподобия и время ответа при N = 1, 4, 16.
