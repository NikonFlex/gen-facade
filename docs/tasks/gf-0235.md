## Описание из трекера

Таблица метрик (`genfacade/metrics/table.py` `_realism`) считает c2st по одной подвыборке с
seed из настройки. На gf#211 одна подвыборка шумела на ±0,024: при seed 0 синтетика «не стала
лучше» (0,723 → 0,727), а среднее по 50 подвыборкам упало с 0,791 до 0,735. С таким шумом
сравнение новой модели с gf#155 ненадёжно.

Что сделать:
- c2st — среднее по R подвыборкам (R — настройка `[realism]` в `config/metrics.toml`) и
  разброс (стандартное отклонение) отдельной колонкой;
- `genfacade realtest` и таблица метрик пишут оба числа; `docs/metrics-results.md` — строки
  gf#210 пересчитаны в новом виде.

`openspec/specs/evaluation/spec.md` — «Пять групп метрик»

**Готово, когда:**
- тест: c2st двух выборок из одного распределения при R подвыборках ближе к 0,5, чем худшая
  из одиночных, и разброс больше нуля; тест красный, если R игнорируется;
- на синтетике gf#211 (старая и новая, 200 домов) таблица даёт числа, совпадающие с замером
  субагента gf#211 в пределах разброса;
- строки gf#210 в `docs/metrics-results.md` пересчитаны.

Датчик: разброс c2st реальных против реальных при R = 1, 10, 50.
