## Описание из трекера

Хозяин отходит, пока Claude работает, и не знает, когда тот закончил. Хуки Claude Code шлют
пинг в тему «Claude» Telegram-группы: Claude закончил ответ или ждёт разрешения — если с
просьбы хозяина прошло не меньше порога (короткие ответы, пока хозяин рядом, не шумят).

Что сделать:
- `tools/tg_ping.py`: `start` (хук UserPromptSubmit — время начала хода по `session_id`),
  `stop` (хук Stop — «закончил · N мин · ветка», начало последнего сообщения),
  `wait` (хук Notification, `permission_prompt` — «ждёт разрешения: …»); порог — в
  `.claude/ping.json`; отправка — `tg_inbox.send`; без токена или темы — молча выход 0;
- тема «Claude» — бот создаёт сам (`createForumTopic`), номер — `TELEGRAM_THREAD_CLAUDE`;
- хуки в `.claude/settings.json`, Stop и Notification — в фоне (`async`), чтобы не тормозить;
- самопроверка в `check.sh`; строка в README.

Готово, когда:
- `tools/tg_ping.py --selftest` зелёный: ход короче порога — молчит, длиннее — текст с
  длительностью, веткой и началом ответа; без токена — выход 0; краснеет на поломке;
- живой ход длиннее порога → пинг в теме «Claude»; короткий ход → пинга нет;
- `sh tools/check.sh` проходит.
