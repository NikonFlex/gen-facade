## Описание из трекера

Препроцессор плана по `specs/plan-input.md`: SVG GenPlan → внутренний `Plan` и стороны дома.
- разбор SVG по цветам (стены, окна, двери), слияние перекрывающихся стен, наружный контур;
- стороны, проекция проёмов на стороны, запретные зоны (примыкание внутренних стен), перевод в метры;
- режим 1 (глухой куб): заделать наружные разрывы, кроме входа; режим 2: проёмы из плана;
- дефектный план — отказ с причиной.

**Готово, когда:** выполнены критерии приёмки `specs/plan-input.md` (пример GenPlan, коробка без ложных проёмов, глухой режим, план без входа), есть тесты.
