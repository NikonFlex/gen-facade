## Описание из трекера

Все метрики сейчас считаются против синтетики: они отвечают на «выучила ли модель генератор», а не
«похоже ли на настоящие дома» (`docs/metrics-results.md`, оговорки). Пилот BuildingNet сделан
(gf#40), следующий шаг из его «Чем возобновлять» — извлечение в наш формат.

Что сделать:
- до кода — лицензия BuildingNet по первоисточнику (`data: BuildingNet только некоммерчески` — ⚪);
- извлечение коттеджей BuildingNet → `FacadeSheet` (стены, проёмы, классы элементов), разбиение
  без утечек; хранение — вне git, как синтетика;
- `genfacade metrics -r <реальные>` — строки модели, генератора и правила GenPlan против реальных
  домов, калибровка подменами на них.

`openspec/specs/data/spec.md` — «Коттеджи из BuildingNet», «Извлечение BuildingNet», «BuildingNet только некоммерчески», «Тест — только реальные данные», «Реальные коттеджи — тест», «Разбиение без утечек»
`openspec/specs/evaluation/spec.md` — «Основная таблица на реальном тесте»

**Готово, когда:**
- N реальных коттеджей (число — по пилоту gf#40) лежат листами `<дом>.json`, валидатор без ошибок,
  5 случайных посмотрены глазами;
- таблица `genfacade metrics` против них — в низу задачи и в `docs/metrics-results.md`;
- требования задачи в таблице требований — ✅ или 🟡 с остатком.

Датчик: доля домов BuildingNet, извлечённых без ошибок валидатора.

## Что установлено

- **Условия использования** [проверено 17.10: форма https://forms.gle/jFQpoRzRkrTCaTzX8, текст
  https://bit.ly/3lrC61o — прочитан пересказом WebFetch, не дословно; репозиторий
  github.com/buildingnet/buildingnet_dataset — лицензии нет (`gh api`: license null, 75 звёзд,
  последний push 26.06.2023)]: только некоммерческие исследования и обучение; без гарантий;
  исследователь отвечает за копии моделей и возмещает иски; коллегам — только на тех же условиях;
  авторы могут закрыть доступ; право Массачусетса. Про публикацию производных (листы, рисунки в
  ВКР) — ни слова: не запрещено и не разрешено явно. Модели — производные 3D Warehouse; FAQ Trimble
  считает сбор моделей в исследовательский проект «impermissible aggregation» без согласия авторов
  [пересказ]. Вывод: меши не выкладывать (как в `data: BuildingNet только некоммерчески`); листы
  целиком — вопрос авторам или научрукам. Код BuildingNet без лицензии — не копировать.
- **Данные у нас** [проверено 17.10: `data/buildingnet/`, вне git, 454 МБ]: метки v1 (face/component
  labels, faceindex_componentID, `dataset_models.txt`, `3dwarehouse_ids.csv`), 12 домов OBJ в
  `sample/`, скрипты пилота (`rzip.py` вынимает модели из zip на Drive по HTTP Range). Полного
  OBJ_MODELS нет; все house+villa — 1,7 ГБ сжато (gf-0040), свободно на диске ~5 ГБ.
- **Официальный тест** [проверено: `probe/v1/test_split.txt`]: 180 строк, из них RESIDENTIALhouse 91 и
  RESIDENTIALvilla 23 — 114 коттеджей; train/val-разбиение не скачано.
- **Компоненты в OBJ** [проверено: `RESIDENTIALhouse_mesh3240.obj` — 423 строки `o`, 0 строк `g`]:
  объект `o` = компонент BuildingNet (окно целиком), группировать грани самим не нужно. Уточнение к
  gf-0040 («OBJ без групп» — верно про `g`, но компоненты есть).
- **Масштаб**: метров нет, модель центрирована, наибольшая сторона = 1, Y вверх [субагент: min/max
  вершин house3240; не перепроверено]. Метры — по высоте двери, как в спеке.
- **Классы**: 31 + undetermined; подоконника, карниза, цоколя, поясов нет [субагент: словарь
  `toplabels` в GNN/utils/IOU.py; совпадает с gf-0040]. У house3240 ~42 % граней — undetermined.
- **Готового извлечения в 2D-фасады нет** [субагент 17.10: gh search «buildingnet», «buildingnet
  facade», «facade elevation extraction mesh», «3d warehouse facade windows doors», «house mesh
  floorplan elevation labeled»; WebSearch «BuildingNet orthographic facade elevation windows doors»,
  «3D building semantic segmentation to facade elevation 2D windows doors rectangles»; Papers with
  Code — производных нет]. Близкое, не для коттеджей: ZAHA (облака точек), Texture2LoD3/ReLoD3
  (arXiv 2504.05249) [не открывались]. Извлекатель пишем сами — довод к новизне.

## Что осталось

  научруки — вопрос в `openspec/README.md` по слову хозяина).
- План извлечения (субагент, не проверен кодом): отбор house|villa → компоненты по `o` + метки →
  главный дом кластером (без растений, машин, земли) → контур и стороны в плане → масштаб по двери

  масштаб без дверей, повороты и Г-образные контуры, окружение, ниши, 42 % undetermined.
