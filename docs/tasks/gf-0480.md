## Готово, когда

- Без флага страница смотрелки не загружает скрипт, адрес Braille возвращает 404. С флагом `genfacade serve` отдаёт скрипт и доступен `window.__agent`.
- С заготовленным планом и стабом Braille проходит сценарий «выбрать план → запустить → открыть лист», сохраняет наблюдения и снимок. SVG и JSON доступны для проверенного прогона.
- Проход в браузере виден на снимке, тест переключателя и быстрые проверки проходят локально.

## Что установлено

- По уточнению хозяина подключён upstream agent-braille `e7e5b59`. От первой интеграции через Welta сохранён вход по `AGENT_API=1`. Включённый FastAPI отдаёт браузерный пакет, в котором `window.__agent` является алиасом `window.stalker`. В обычном запуске маршрут скрипта отвечает 404.
- Пакет собирается из исходников upstream. Используются штатные CLI, запись и воспроизведение API. Смотрелка выставляет состояние экрана при реальной загрузке и отдаёт результаты POST-запросов для `--sensors`.
