## Описание из трекера

После стража gf#242 на полном реальном тесте (GPU run 41217125093, модель gf#212 run 41186638178)
глухих стен нет, брака на годных листах нет, но окон на стену 2,75 («окна из плана») и 2,98
(глухой) против 2,02 у настоящих домов (было 2,21 и 0,78); годных 26/27 и 25/27 при 27/27 у gf#155.
В «окнах из плана» модель иногда пишет десятки окон, налезающих друг на друга (отказ после 5
попыток), — было и до нового стража (gf#242, «Что осталось»).

Что сделать:
- датчик: окон на стену и на метр стены по режимам и этажам — модель, gf#155, настоящие дома;
  причины отказов по видам;
- разобрать, откуда избыток: страж (запрет конца стены без зоны, место под типоразмер), данные
  синтетики (окон на стену у генератора 2,35), сэмплирование;
- поправить причину; «лучший из N» по метрике gf#243 — как вариант выбора ответа;
- повторный реальный тест на GPU — по слову хозяина.

`openspec/specs/generation/spec.md` — «Брак — заново»

**Готово, когда:**
- окон на стену у модели в обоих режимах в пределах ±15 % от настоящих домов;
- годных не меньше 26 из 27 в каждом режиме, брак на годных — 0;
- числа — в `docs/metrics-results.md`.

Датчик: окон на стену и годных по режимам на 27 домах реального теста.
