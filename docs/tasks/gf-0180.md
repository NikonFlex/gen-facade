## Описание из трекера

По спеке тест — только реальные данные: ручная разметка фасадов коттеджей с планами (Solar
Decathlon, FreeFarmhouse, рендеры Егора), BuildingNet — отдельной колонкой (gf#154). Сейчас все
метрики считаются против синтетики или BuildingNet; главной таблицы на реальном тесте нет.

Что сделать:
- разведка: сколько домов в каждом источнике, форматы чертежей, есть ли план и все фасады,
  этажность и форма контура, лицензии;
- способ разметки с оценкой времени на дом (вытащить окна и двери из векторного чертежа и поправить,
  или разметка по картинке с масштабом); выбор с отброшенным — в `docs/decisions.md`;
- разметить дома в формат примера (`Sample`: план и фасады), разбиение по домам, валидатор;
- `genfacade metrics` против них — главная таблица.

`openspec/specs/data/spec.md` — «Реальные коттеджи — тест», «Тест — только реальные данные», «Разбиение без утечек»
`openspec/specs/evaluation/spec.md` — «Основная таблица на реальном тесте»

**Готово, когда:**
- размечено не меньше домов, чем решено по разведке (число — после неё), листы `<дом>.json`
  проходят валидатор, 5 случайных посмотрены глазами;
- таблица `genfacade metrics` против них — в `docs/metrics-results.md` и в низу задачи;
- требования задачи — ✅ или 🟡 с остатком.

```python
"""Папки листов для таблицы против реального теста (gf#180): эталон — 20 размеченных домов,
генератор синтетики (val), правило GenPlan, подмены random/foreign/empty, модель шага 4 (шаги 4–5,
до attempts попыток, с запретом). Брак модели — {"error": …}, как у eval.
Запуск: PYTHONPATH=. python tmp/gf180/real_rows.py <out>"""
import json, sys, time
from pathlib import Path
import numpy
from genfacade import baselines, config, pipeline
from genfacade.baselines import Baseline
from genfacade.metrics import calibrate
from genfacade.models.stub import ModelError
from genfacade.schema import Mode, Source, Split
from genfacade.train import tokens

cfg, out = config.load(), Path(sys.argv[1])
real = calibrate.houses(Source.MANUAL, Split.TEST, 0, cfg)
synth = calibrate.houses(Source.SYNTHETIC, Split.VAL, 0, cfg)
for mode in Mode:
    sheets = [tokens.given_sides(s, mode) for s in real.values()]
    calibrate.write(out / mode / "reference", list(real), sheets)
    calibrate.write(out / mode / "generator", list(synth), [tokens.given_sides(s, mode) for s in synth.values()])
    baselines.run(Baseline.GENPLAN, out / mode / "reference", cfg, out / mode / "genplan")
    for name in ("random", "foreign", "empty"):
        calibrate.write(out / mode / name, list(real), calibrate.ROWS[name](sheets, numpy.random.default_rng(cfg.metrics.seed)))
    folder, ok, why, start = out / mode / "model", 0, {}, time.time()
    folder.mkdir(parents=True, exist_ok=True)
    for name, sheet in zip(real, sheets):
        try:
            got = pipeline._layout(tokens.bare(sheet), pipeline.PlanRun(plan=name, text="", mode=mode), cfg).sheet
            text, ok = got.model_dump_json(), ok + 1
        except ModelError as e:
            text, why[name] = json.dumps({"error": str(e)}, ensure_ascii=False), str(e)[:160]
        (folder / f"{name}.json").write_text(text)
    print(mode, "модель: годных", ok, "из", len(real), f"{time.time() - start:.0f} с", flush=True)
    for k, v in why.items(): print("  ", k, v, flush=True)
```
