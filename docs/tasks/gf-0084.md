## Описание из трекера

События репозитория уходят в тему «Задачи и PR» группы хозяина, чтобы прогресс был виден
без захода на GitHub. Образец — действие `telegram-send` из dgtlU.

Что сделать:
- одно действие отправки (`.github/actions/telegram-send/`): текст из файла, разметка
  HTML, повторы на обрыв, 429 и 5xx; без токена или чата — предупреждение и выход 0;
  сбой отправки не красит прогон;
- workflow на события: задача заведена; PR открыт или готов к ревью (черновик молчит);
  PR слит; задача закрыта — с текстом комментария «Что установлено», если он есть;
  красный `check.yml` на `main`;
- адрес — секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_THREAD_TASKS`
  (общие со сборщиком);
- тест действия с подставным сервером через `TELEGRAM_API_BASE`.

Готово, когда:
- тест на подставном сервере: 429 → повтор и успех; «chat not found» → без повторов;
  без токена → выход 0; тест краснеет, если убрать повтор;
- открыт тестовый PR → в теме «Задачи и PR» сообщение со ссылкой; закрыта тестовая
  задача → сообщение с «Что установлено»;
- `sh tools/check.sh` проходит.
