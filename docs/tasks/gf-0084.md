## Описание из трекера

События репозитория уходят в тему «Задачи и PR» группы хозяина, чтобы прогресс был виден
без захода на GitHub. Образец — действие `telegram-send` из dgtlU.

Что сделать:
- отправка — та же, что у сборщика: `tools/tg_inbox.py send --topic tasks` (повторы на
  обрыв, 429 и 5xx, деление длинного текста, без токена — выход 0), отдельного действия
  на curl не заводим — второй код того же самого (08.10); текст — `tools/tg_notify.py` из
  события GitHub; сбой отправки не красит прогон;
- workflow на события: задача заведена; PR открыт или готов к ревью (черновик молчит);
  PR слит; задача закрыта — с текстом комментария «Что установлено», если он есть;
  красный `check.yml` на `main`;
- адрес — секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_THREAD_TASKS`
  (общие со сборщиком);
- самопроверка `tg_notify.py`: текст на каждое событие и молчание, где шуметь не надо.

Готово, когда:
- повторы и отказы отправки — самопроверка `tg_inbox.py` (429/5xx → повтор и успех,
  400 → без повторов, без токена → выход 0; краснеет без повтора — проверено в gf#82);
  `tg_notify.py --selftest` зелёный и краснеет на поломке;
- открыт тестовый PR → в теме «Задачи и PR» сообщение со ссылкой; закрыта тестовая
  задача → сообщение с «Что установлено»;
- `sh tools/check.sh` проходит.
