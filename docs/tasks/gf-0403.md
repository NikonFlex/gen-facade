Нынешние допуски против реальных домов (доля в допуске): ряды с верхом в `align_m` — тест 90,6 %,
BuildingNet 48,7 %; окна в `snap_m` от линии этажа — 88,6 % / 49,4 %; в `window_jump_m` —
94,8 % / 61,7 %; оси с центрами в `axis_tol_m` — 90,7 % / 70,2 %; пары «почти на оси»
(0,01 < d ≤ 0,05) — 1,5 % / 12,5 %. Вывод: на тесте нынешние допуски близки к P90, P95 теста
(верх 0,31, линия этажа 0,30) совпадает с `window_jump_m`; `align_m` на 0,05 бракует каждый
десятый ряд настоящих домов.

Оговорка к BuildingNet: этажи и окна там из разметки меша (gf#186 и далее), хвосты (P95 верха
ряда 2,3 м — выше этажа) — шум назначения этажей, а не разброс дома; допуск по BuildingNet
вместе с тестом брать нельзя без отсечки. Поэтому столбец «предварительно» — по тесту (49), а
BuildingNet — для сравнения; окончательное решение — на русских домах (gf#342). Предложенный
пересмотр на глаз по тесту: `align_m` 0,05 → ≈0,3 не годится (захватит окна разной высоты
намеренно) — вопрос к хозяину, какой процентиль брать (P90 теста: верх 0,046, ось 0,009).
