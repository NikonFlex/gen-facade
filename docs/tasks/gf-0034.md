## Что установлено

Всё `[проверено]` чтением кода GenPlan, клон HEAD 2ed651c (2026-09-11), лицензии в репо нет.

1. **Формат.** SVG через drawsvg, только `<rect>` (+ `<path>` дугой для открытых
   дверей). Внутри — список `Rect(start_point, end_point, color, rect_type)`
   (`dto/rect.py`). Тип в SVG не пишется, **различается только цветом**:
   стены `#000000`, окна `#99ccff`, двери `[150,80,50]` / дуга (`config.py`).
   Примеры `examples/svgs/test1..3.svg`: 26 / 92 / 13 прямоугольников стен.
2. **Стены.** Axis-aligned прямоугольники с толщиной (min 3 px), не линии и не
   полигоны. Получаются векторизацией растра диффузии: углы
   `cv2.goodFeaturesToTrack` → перебор прямоугольников → `merge_similar_rects`
   (`vectorization/vectorization.py:153-184`). Прямоугольники **перекрываются**,
   топологии (граф стен, стыки) нет. Наружный контур явно не хранится — его
   вычисляет 3D-конвертер заливкой (`three_dimensional/convertor.py:46`
   `find_outside_corner_points`).
3. **Окна и двери.** Диффузия рисует только стены с разрывами. Проём = промежуток
   между двумя коллинеарными стенами (`decorator/decoration.py:9` `find_openings`),
   наружный/внутренний — по эвристике (`:51`). Самый узкий наружный → входная
   дверь, прочие наружные → окна, внутренние → двери (`:158-174`). Положение и
   ширина окна = разрыв в стене. Типы окон по высоте — три (`WindowSizeType`),
   выбираются одни на весь дом.
4. **Типов комнат нет.** `RectType`: UNKNOWN, WALL, DOOR, WINDOW. Комнат как
   объектов нет вообще.
5. **Высоты, этажность, крыша.**
   - Этаж **один**, этажности нет.
   - Высота стены: `WallSizeType` 250/275/300, окна: `WindowSizeType` доли высоты
     стены (0.4–0.9 / 0.2–0.9 / 0.0–1.0). Оба выбирает zero-shot BART
     (`facebook/bart-large-mnli`) по описанию (`three_dimensional/classifier.py:33`,
     вызов `convertor.py:484`).
   - Крыша всегда двускатная, 30° (`convertor.py:262`, `slopes_count=2` на `:508`),
     ориентация — от стороны входной двери (`get_door_type`, `:402`).
6. **Единицы — пиксели** (`Point` приводит к int). Масштаба в метры нет: он
   **выводится из ширины входной двери**, принятой за 90 см —
   `door_height = 200/90 · ширина_двери_px` (`convertor.py:249`), от неё высота
   стены (`:253`). То есть весь дом масштабируется по одному проёму.
   В IFC вершины делятся на 100 при единице MILLI (`ifc_converter.py:39,64`) —
   выглядит несогласованно, `[не проверено]` запуском.

**Итог для фасадного модуля.** Из плана GenPlan можно взять: контур дома,
разрывы в наружных стенах (x-позиция и ширина окон/двери на фасаде), сторону
входа, тип высоты. Нельзя: комнаты, этажность, реальный масштаб (только через
дверь), чистую топологию стен — нужен свой препроцессинг (слияние
перекрывающихся прямоугольников, выделение четырёх наружных сторон).
