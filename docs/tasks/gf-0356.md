## Гайд для следующих страниц (2026-11-08, Opus)

**Где тема.** `genfacade/viewer/static/theme.css` — единственное место цветов, шрифтов, радиусов
и общих компонентов; каждая страница подключает его **первым**, потом свой CSS. В своём CSS страницы
— только раскладка (grid, отступы, размеры) на `var(--…)`; литералов цвета нет. Токены: поверхности
`--bg` → `--panel` → `--panel-2` → `--panel-3`; текст `--ink`, `--muted`, `--faint` (на `--panel`
контраст 14,9 / 7,0 / 5,8 — проверено расчётом WCAG); `--line`, `--line-strong`; акцент `--accent`
(#f0a35b), текст на нём `--accent-ink`, подложка `--accent-soft`; состояния `--ok`, `--warn`,
`--danger` и их `-soft`; `--paper` — светлая подложка чертежей (лист, план, образцы каталога
рисуются светлыми, как бумага на тёмном столе — не перекрашивать сами SVG). `style.css` — раскладка
только index.html (Дома, Новый дом, Данные, экран дома).

**Шапка.** `static/shell.js`: `topbar(узел, раздел)` рисует марку, вкладки и «+ Новый дом»; список

`<header id="topbar"></header>` и вызов `topbar($("topbar"), "<раздел>")`; текущий раздел —
`aria-current="page"` (`markCurrent`). Каталог, Разметка и Проверка пока со своими старыми шапками —
заменить на этот вызов, свои `.topbar`-разметки удалить.

**Компоненты (theme.css).** Страница: `.page` › `.page-head` (h1, `.count`, `.end` справа) ›
содержимое; `.eyebrow` — подпись разделом капсом; `.empty-note`. Кнопки: `.btn` (`.primary` —
одно главное действие на экране, `.ghost`, `.danger`, `.on` — включённый переключатель),
`.icon-btn` с `aria-label`. Подписи: `.chip` (`.accent`, `.ok`, `.warn`, `.bad`). Фильтры:
`.filters` › `.filter-group` (`role=group`, `aria-label`) › `.filter-label` + `button.filter` с
