## Что установлено

- `genfacade run план.svg -t "…" [-m blind] [-s N]` → `outputs/runs/<id>/`: `request.json`,
  `input_plan.svg`, `01_spec.json` (дом из `config/house.json` с цветами палитры), `02_plan.json/svg`,
  `03_unfold.svg`, `04_layout.svg`, `05_snapped.svg` + `violations.json`, `06_sheet.svg`, `sheet.json`,
  `preview.png`, `meta.json` (попытки, использованный seed). Дефектный план — отказ с причиной
  (CLI — код 1, смотрелка — 400).
- Повтор при браке: следующий seed, не больше `checks.max_attempts`, и стоп, если ошибки те же —
  так окно плана в запретной зоне (дефект GenPlan) не гоняет 5 попыток впустую. Выбирается попытка
  с наименьшим числом ошибок. Тест с подложенной ошибкой: 3 попытки, взят seed+2.
- Конёк — вдоль длинной стороны плана (`ridge_along_longest`).
- На шагах 4–5 поверх листа — запретные зоны и рамки нарушений (слой без `data-cls`, разбор листа
  его не видит); на итоговом листе их нет.
- Смотрелка: форма «план + описание» на главной (план из `viewer.plans_dirs` или свой SVG, режим,
  seed), шаг 1 — JSON дома и сводка, слои «запретные зоны» и «нарушения», счётчик
  нарушений на шаге 5, вход прогона — запрос JSON с перезапуском. Проверено скриншотами
  (headless shell): главная, шаги 1, 2, 5, 6, вход, режим 1, правка seed → новый прогон, ширина
  400 px, профиль с кэшем; ошибок в консоли нет.
- По ходу найдено и исправлено: план без стен падал `AttributeError` вместо отказа (тест смотрелки);
  на ширине 400 px кнопки файлов закрывали «назад» (было с этапа 0); миниатюра плана обрезалась.
