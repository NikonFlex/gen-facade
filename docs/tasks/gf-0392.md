## Описание из трекера

Егор 09.11 (источник «Созвон 09.11», стр. 25): «можно попробовать BIM-модель погенерить». Сейчас 3D — меш; при этом стены по плану, проёмы с размерами, этажи и материалы у нас уже объекты. Ближайшая работа Text2BIM (текст → BIM без плана) пишет, что расставить окна у неё не получается. Вне релиза ВКР (`openspec/README.md`, «Границы релиза»: 3D) — направление для статьи.

Что сделать: найти готовое (IfcOpenShell — лицензия, живость), выгрузка листа дома в IFC: IfcWall по сторонам, IfcWindow/IfcDoor в стенах, IfcSlab этажей, IfcRoof; проверка открытием в просмотрщике IFC.
