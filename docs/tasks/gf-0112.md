## Что установлено

Источник — навык `plugin-authoring` Claude Code 2.1.292 (SKILL.md, `reference.md`) и объявления
API `types/claude-code.d.ts` этой сборки, 21 147 строк `[проверено 08.10, прочитано]`.

- **Мод** — плагин из «функциональных хуков»: папка с `.claude-plugin/plugin.json`,
  `hooks/hooks.json` и модулем на TypeScript с `register(on, options)`. Хук — `($, e, next)`:
  `$` — интерфейс движка (интерфейс, модель, сессия, промпт, инструменты, файлы, хранилище,
  таймеры, процессы, сеть), `next(e)` — дальше по цепочке. Модуль работает в своей среде без
  Node и DOM, всё наружу — через `$`.
- **Что умеет:** панель (`Pane`), полоса над вводом (`AbovePrompt`), строка состояния
  (`$.ui.status`), всплывающее уведомление (`$.ui.toast`), звук; перехват вызова инструмента
  (`tool.call` — запретить, переписать, среагировать), промпта (`prompt.submit`), системного
  промпта (`prompt.compose`); свои слэш-команды, инструменты для модели (`mcp__<plugin>__<name>`)
  и типы субагентов; таймеры (`$.clock.every`), запуск команд (`$.process.run`), чтение файлов
  (`$.fs`), состояние на сессию (`$.state`) и между сессиями (`$.store`), вызов модели
  (`$.model.complete`, `$.model.fork` — вопрос по текущей переписке с кэшем).
- **Отличие от наших хуков в `.claude/settings.json`:** те — команды оболочки, лежат в репо и
  работают у любого, кто открыл проект; рисовать не умеют. Мод рисует, держит состояние и
  таймеры, но это личный плагин: грузится из папки модов сессии, `--plugin-dir`,
  `CLAUDE_CODE_PLUGIN_DIRS` (только из `~/.claude/settings.json`, не из проекта) или ставится
  из маркетплейса (`/plugin install <mod> --marketplace <owner>/<repo>`, файл
  `.claude-plugin/marketplace.json` в репо).
- **API в раннем доступе** и меняется между выпусками — авторитет только файл типов своей
  сборки. Запреты (guard) надёжнее оставлять в хуках настроек: проще и не зависят от API.
- **Поверхности:** у VS Code (где работает хозяин) элементы Box, Text, Button, Input, Select,
  Svg, Link, Code, Markdown — нет `Raster` и `Image` (они только в терминале), зато есть `Svg`.
  Рисует ли расширение VS Code панель и полосу — «где у поверхности есть место»
  `[не проверено: в типах так, вживую не пробовали]`.
- Проверка мода: `claude plugin validate <папка>`, тесты `claude plugin test <папка>`
  (`*.test.ts`, `claude-code/testing`), `tsc -p <папка>`.
