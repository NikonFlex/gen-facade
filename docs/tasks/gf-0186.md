Порядок (по шагам, с отчётом хозяину после каждого; обучение — только по «обучай»):
1. **План BuildingNet без налезаний.** Проёмы первого этажа, перекрытые по x (окно над дверью, окно
   в окне; простенок p10 −1,4 м), в плане сливать в один проём — как разрыв стены в настоящем
   плане; решение — `docs/decisions.md`, тест с порчей; `genfacade buildingnet` заново (данные —
   `data/buildingnet/`, вне git), эталон таблицы — `outputs/gf154/<режим>/reference` пересобрать
   скриптом из низа `docs/tasks/gf-0154.md`. Перемерить датчик на смеси (`data/models/layout-186b`).
2. **Чекпойнты по эпохам.** `genfacade train` сохраняет модель каждые N эпох (настройка в
   `config/train.toml`), артефакт job train — со всеми. Пример плана GenPlan и BuildingNet на
   GPU-машину не попадают (вне git, BuildingNet — только некоммерчески), поэтому перенос меряется
   локально по чекпойнтам.
3. **Обучение** смеси 70/30, 6 × 384 (`config/train.toml` вернуть с 8 × 512), 10 000 домов, 24 эпохи,
   чекпойнт каждые 4. Датчик переноса по каждому: план GenPlan 20 seed × 4 строки
   (`genplan20.sh`-подобный цикл: `genfacade run materials/genplan-plan-example.svg -t "A
   {one,two}-storey house with a flat roof." -m {with_openings,blind}` с `attempts = 1`, `seed = 0…19`)
   и 30 домов BuildingNet (шаги 4–5, 5 попыток с запретом, причина каждой). Выбрать эпоху.
4. **Оценка** выбранной: eval/visual на GPU, `docs/metrics-results.md`, PR.

Скрипты датчиков сессии 21–22.10 — во временной папке, не в репо: их стоит положить в `tools/`
