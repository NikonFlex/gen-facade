  посмотреть глазами; проверить, дают ли текстуры и материалы зоны отделки;

## Что установлено

Всё `[проверено лично, 29.09]`, скрипты — `data/buildingnet/probe/` (вне git).

- **Три версии.** Структура папок одинаковая (OBJ_MODELS.zip, POINT_CLOUDS.zip,
  model_data, splits, 3DWarehouse_IDs); в v0 и v0.1 ещё данные для GNN.
  Архивы OBJ: v0 — 6.58 ГБ, v0.1 — 6.40 ГБ, v1 — 6.05 ГБ. Drive отдаёт их
  по HTTP Range — модели вынимаются выборочно, без скачивания архива (`rzip.py`).
- **Моделей** 2000 / 1937 / 1848; жилых 1266 / 1243 / 1225; из них house + villa
  в v1 — **752 + 376 = 1128**, остальное «жилое» — офисы, храмы, дворцы.
  В v1 нет моделей, которых не было бы в v0 (минус 151 дубль).
- **v1 размечена полнее** на тех же 1128 домах: окон +17%, дверей +24%,
  ставен +68%, колонн +47%; неразмеченных компонентов 51.2% против 56.8%.
  v0 и v0.1 по меткам совпадают. Окна есть у 1096 домов, двери — у 988.
- **Классы** (31, из `GNN/utils/IOU.py` репозитория): wall, window, door, roof,
  stairs, column, railing_baluster, chimney, balcony_patio, garage, dormer,
  awning, shutters, beam_frame, entrance_gate, arch… — уровни 1 и 3 наших
  (`specs/facade.md`) покрыты; подоконников, карнизов и цоколя как классов нет.
- **Формат.** OBJ без групп; метка — на каждой грани (`face_labels/<model>.json`,
  номер грани = порядок `f` в OBJ, число совпадает); материал грани — `usemtl`.
  Геометрия нормирована в единичный куб, ось Y вверх — метры восстанавливаем
  по высоте дверей (≈2.1 м).
- **Материалы осмысленные.** Имена текстур жилых моделей — стандартные
  материалы SketchUp: wood 5.6 тыс., stone 1.8 тыс., tile 1.8 тыс., brick 0.9 тыс.,
  siding 554, stucco 372, roofing/shingles ~1 тыс. Значит, зону отделки стены
  можно определить по материалу её граней — уровень 2 без ручной разметки.
- **Объём.** Все house + villa v1 в сжатом виде — 1.7 ГБ, медиана модели 0.5 МБ;
  помещаются на диск (свободно 6.5 ГБ).

## Выборка из 12 домов v1 — посмотрел глазами (29.09)

Рендеры: ортофасады ±x, ±z и план, раскраска по меткам, масштаб по дверям
(90-й перцентиль высоты граней двери = 2.1 м). Два примера — в
`docs/assets/buildingnet-house3240.png`, `buildingnet-house8147.png`.

| Дом | Итог |
|---|---|
| house3240, house8147, house7447, villa2972, villa4686, house1018 | **годны сразу**: окна, двери, гаражи, слуховые окна, колонны крыльца размечены верно; размеры правдоподобны (8.5×14, 19×10, 20×18 м) |
| house0879 | годен, но **масштаб не восстановлен** — обычных дверей нет, только гаражные ворота |
| house1946, house6604, house1264 | в модели **окружение**: соседние дома, бассейн, машины, растения — надо вырезать главный дом |
| villa0659 | дом **повёрнут на 45°** в плане — нужны главные оси, а не оси модели |
| villa1457 | A-frame, 92% граней не размечено — брак |

Оценка по выборке (не мерил на всех): ~половина годна сразу, ~треть — после
вырезки дома и поворота, ~1/10 — брак. Из 1128 house + villa — порядка
700–900 годных домов, ~3–4 тыс. стен.

**Материалы стен** осмысленны примерно у половины: siding/brick (3240),
siding/stone (8147), concrete/brick/wood (2972), concrete/stucco (1264),
brick/siding (1946), wood (0659); у остальных — «material», «Color_G10».

**Геометрия во всех трёх версиях одинаковая** (md5 OBJ совпадает для 3 домов),
различаются только метки — берём v1.
