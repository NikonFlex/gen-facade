Шаг 4 из плана первой модели; после того, как модель стоит на шаге 4 (gf#107). Цель — понять, работает
ли цепочка, а не результат для защиты (модель учится на однообразной синтетике).

- Две цифры на val: доля разобранных ответов и доля домов без ошибок валидатора.
- Предложено 02.10, хозяин не подтверждал: сравнение с необученной моделью и с правилом
  синтетики; сходство статистики (окон на стену, размеры, глухие стены); доля дословных
  повторов train; реакция на изменение условия. **Перед началом — спросить хозяина, что берём.**

Готово, когда:

- одна команда печатает обе цифры по val в обоих режимах;
- выбранные хозяином проверки посчитаны и записаны в файл задачи с числами;
- вывод — хватает ли этой модели, чтобы идти дальше, — назван хозяину.
