## Описание из трекера

Базовый инструмент: из разметки CMP получить валидный SVG-чертёж фасада.
Он же даёт ground truth для обучения и для метрик.

Парсер с учётом подводных камней формата уже есть: `tools/cmp.py`.

**Осторожно:** в CMP `<x>` — вертикальная ось, `<y>` — горизонтальная.
Подробности в докстринге `tools/cmp.py`.

**Готово, когда:** скрипт конвертирует все 606 аннотаций без ошибок,
выборочные результаты открываются в векторном редакторе и визуально совпадают с фото.

## Что установлено

- **`<x>` в CMP — вертикальная ось (строка, масштаб по высоте), `<y>` —
  горизонтальная.** Соглашение (row, col) как в MATLAB, на странице датасета
  не описано. Проверено сверкой с масками: при таком прочтении медианный
  IoU 0.978, при интуитивном — 0.000.
- Формат XML неоднороден: в части файлов значения обёрнуты переводами строк.
  Наивная регулярка падает на половине датасета.
- Все 51 769 объектов — ровно 2 координаты x и 2 координаты y, исключений нет.
- `flag` всегда равен 1 — информации не несёт.
- Класс `background` в XML не появляется, только в масках PNG.
- `facade` встречается 689 раз на 606 изображений — на части кадров размечено
  больше одной плоскости фасада.
