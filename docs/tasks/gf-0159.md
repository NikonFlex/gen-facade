## Описание из трекера

Хозяин смотрит результаты с телефона: таблицы метрик и сводки агент шлёт файлом в тему
«Результаты» Telegram-группы, а в чате отвечает коротко (хозяин 17.10). Сейчас `tools/tg_inbox.py
send` шлёт только текст файла сообщением.

Что сделать: команда `send-file --topic T --file F [--caption …]` — `sendDocument` (multipart), с
теми же повторами при обрыве, 429 и 5xx, что у `send`; без токена — предупреждение и выход 0;
самопроверка на подставном сервере (`--selftest`), как у остальных команд. Строка в README
рядом с `send`.

без сценария — инструмент процесса, требований продукта не касается

**Готово, когда:**
- `python3 tools/tg_inbox.py --selftest` проходит, и проверка отправки файла краснеет, если файл не
  уходит multipart-полем `document` в нужную тему;
- `python3 tools/tg_inbox.py send-file --topic results --file docs/metrics-results.md` — файл виден в
  теме «Результаты» (хозяин подтверждает).

Датчик: без датчика — одна команда.
