## Описание из трекера

Метрики (structure, FID/KID, валидность) у модели приемлемые, а дома на глаз не похожи на
настоящие: ни одна метрика не смотрит на подоконники, козырьки, одинаковость окон и ритм
фасада — все считают только окна. Без числа «насколько дом правдоподобен» не измерить ни
синтетику, ни выводимые элементы, ни обратную связь при генерации.

Что сделать:
- слой правил: каждое правило из свода правил фасада (gf#209) — доля
  выполнения на доме; итог — средняя доля и разбивка по правилам;
- слой «отличим ли от настоящего»: классификатор (C2ST, Lopez-Paz 2017) по признакам раскладки
  стены и дома; precision/recall/density/coverage (`prdc`, MIT) — оценка каждого дома;
- калибровка, как принято в проекте: настоящие дома реального теста, подмены (`random`,
  перестановка окон между стенами), синтетика, модель gf#155, правило GenPlan;
- проверка глазом: 20–30 пар «настоящий / сгенерированный» — хозяин ставит, какой правдоподобнее;
  метрика засчитывается, если согласна с ним;
- столбец в таблице метрик (`genfacade metrics`) и строка в `docs/metrics-results.md`.

`openspec/specs/evaluation/spec.md` — «Пять групп метрик», «Калибровка допусков», «Основная таблица на реальном тесте»

**Готово, когда:**
- тест: настоящий дом получает оценку выше, чем тот же дом с подменой `random`; тест красный,
  если правило считать наоборот;
- на 28 домах реального теста средняя оценка настоящих выше каждой подмены по обоим слоям;
- согласие метрики с оценкой хозяина на парах — число в `docs/metrics-results.md`;
- столбец есть в таблице метрик для модели, правила GenPlan и синтетики.

Датчик: оценка по слоям для настоящих домов, подмен, синтетики, модели и правила GenPlan.

## Что установлено

- Литература, 27.10 (разведка субагента; страницы открыты им, мной не перепроверены):
  архитектурные принципы как энергия разбора фасада — ATLAS, Martinović и др., IJCV 2016,
  doi:10.1007/s11263-015-0868-z (табл. 2: выравнивание, похожесть окон, симметрия, совместная
  встречаемость, дверь на земле); метрики правдоподобия генерации по ним не нашлось (arXiv, ACM,
  CVF). C2ST — Lopez-Paz, Oquab, arXiv:1610.06545. prdc — github.com/clovaai/generative-evaluation-prdc,
  MIT, `pip install prdc`. Layout FID, Alignment, Overlap — Kikuchi и др., ACM MM 2021,
  github.com/ktrk115/const_layout (AGPL-3.0: формулы брать, код не копировать).

- Реальный тест — 27 домов, 110 стен (`genfacade manual`, 29.10; `docs/decisions.md`, 29.10);
  таблица `docs/metrics-results.md` посчитана на 20 домах (25.10) — пересчитать на 27 вместе с
  метрикой правдоподобия (требование `evaluation: Основная таблица на реальном тесте` — 🟡).

- **Метрика на 27 домах, 30.10** [проверено: `genfacade metrics`, `docs/metrics-results.md`]:
  реальные против реальных — rules 0,814, c2st 0,596; модель gf#155 — 0,656 / 0,705; GenPlan —
  0,921 / 0,795; синтетика — 0,983 / 0,800; `random` — 0,461 / 0,677. Правила ловят случайную
  расстановку, c2st — слишком правильные дома; нужны оба слоя.

- **Согласие с хозяином, 30.10** [проверено: 24 пары в 3D вслепую, `outputs/gf210/pairs/`,
  `tmp/gf210/agree.py`]: хозяин узнал настоящий дом в 23 из 24; density дома согласна с ним в 23 из
  24, слой правил — в 15 из 24 (на парах с GenPlan выбирает GenPlan в 11 из 12), сумма слоёв — 0,79.
  Оценка правдоподобия — слой «отличим ли»; правила — перечень нарушений, не оценка.

- **Решение 30.10: precision и recall не делаем** — density и coverage из той же работы (Naeem и
  др., ICML 2020) их исправленные версии: обычные precision и recall раздуваются выбросами эталона
  (шар вокруг выброса накрывает чужие точки); для 27 домов с редкими формами это существенно.
- **Оценка одного дома** — `realism.house_density` (density стен дома против эталона без этого
  дома); по ней — согласие с хозяином 23 из 24; потребитель — «лучший из N» в gf#213.
