## Описание из трекера

Метрики (structure, FID/KID, валидность) у модели приемлемые, а дома на глаз не похожи на
настоящие: ни одна метрика не смотрит на подоконники, козырьки, одинаковость окон и ритм
фасада — все считают только окна. Без числа «насколько дом правдоподобен» не измерить ни
синтетику, ни выводимые элементы, ни обратную связь при генерации.

Что сделать:
- слой правил: каждое правило из свода правил фасада (gf#209) — доля
  выполнения на доме; итог — средняя доля и разбивка по правилам;
- слой «отличим ли от настоящего»: классификатор (C2ST, Lopez-Paz 2017) по признакам раскладки
  стены и дома; precision/recall/density/coverage (`prdc`, MIT) — оценка каждого дома;
- калибровка, как принято в проекте: настоящие дома реального теста, подмены (`random`,
  перестановка окон между стенами), синтетика, модель gf#155, правило GenPlan;
- проверка глазом: 20–30 пар «настоящий / сгенерированный» — хозяин ставит, какой правдоподобнее;
  метрика засчитывается, если согласна с ним;
- столбец в таблице метрик (`genfacade metrics`) и строка в `docs/metrics-results.md`.

`openspec/specs/evaluation/spec.md` — «Пять групп метрик», «Калибровка допусков», «Основная таблица на реальном тесте»

**Готово, когда:**
- тест: настоящий дом получает оценку выше, чем тот же дом с подменой `random`; тест красный,
  если правило считать наоборот;
- на 28 домах реального теста средняя оценка настоящих выше каждой подмены по обоим слоям;
- согласие метрики с оценкой хозяина на парах — число в `docs/metrics-results.md`;
- столбец есть в таблице метрик для модели, правила GenPlan и синтетики.

Датчик: оценка по слоям для настоящих домов, подмен, синтетики, модели и правила GenPlan.
