  `model` — отказ; `opus` — только если задание начинается строкой `Opus: <причина>` с причиной из

  печатает, кому что отдавать (haiku — механика, прогоны, снимки, замеры; sonnet — код по ясной
  постановке; opus — список);
- текст правила в `CLAUDE.md`, «Субагенты»: закрытый список для Opus; прогоны, снимки и замеры по
  артефактам — отдельный Haiku-субагент, даже внутри задачи Sonnet; «не больше трёх пишущих код» —
  иначе только по слову хозяина, названному в ответе;
- самотест сторожа (как у остальных `--selftest`, проверка в `tools/check.sh`).

Требования: без сценария — обвязка агентов, не поведение модуля.

Готово, когда:
- тест: запуск `Agent` с `model: "opus"` без строки `Opus: …` — отказ; с `Opus: формат токенов` —
  пропуск; без `model` — отказ; `sonnet` и `haiku` — пропуск; красное на сломанном стороже;
- `sh tools/check.sh --quick` зелёный, `python3 tools/harness.py` показывает сторож на `Agent`.
