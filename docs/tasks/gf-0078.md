1. **Схема.** В `CLAUDE.md` — скелет схемы строк на 15: вход, семь шагов по строке с
   [модель]/[код], чем отличается режим 2, кто что делает, главная идея. Полный блок
   с подробностями шагов — `.claude/rules/scheme.md` с `paths` (код, спеки, тесты, картинка

   охватывает оба места.
2. **Дельта через перенос строки.** `spec_check.py` ищет дельты построчно и не видит
   пометку, перенесённую на вторую строку: `specs/data.md:73–74` прошла без основания.
   Искать по всему тексту; дать дельте основание (gf#33 — там ответ хозяина 29.09).
