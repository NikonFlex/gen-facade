## Описание из трекера

Хозяин 07.11: в реальном тесте только американские дома (FreeFarmhouse, Solar Decathlon); на
строим.дом.рф у каждого проекта есть план и фасады — заводим и выполняем. Каталог Минстроя (PDF,
прислан хозяином) и альбом КГАСУ — не здесь: КГАСУ не нашёлся (ссылки — 404).

Что известно (разведка 07.11, низ gf#323): у сайта открытый API — список проектов (43 644) и
карточка проекта с этажностью, высотами, материалами, видом крыши и номерами картинок; фасады и
план — JPEG около 2100×1200 с отметками уровней в метрах и размерами в мм. Условия ДОМ.РФ: «в
личных некоммерческих целях», копирование и размещение — с согласия (п. 5.3). Поэтому картинки —
вне git (`data/`), в git — скрипт скачивания и наша разметка (координаты и отметки, снятые с
картинок) со ссылкой на проект.

Что сделать:
- скрипт скачивания: по номеру проекта — карточка JSON, фасады и планы JPEG, лист PDF из них для
  разметчика (1 pt = 1 px); повторный запуск не качает заново; список кандидатов — по полям API
  (1–2 этажа над землёй, есть схема фасадов из четырёх видов и план);
- разметка в метрах: единица разметки — фут или метр (сейчас только фут); прежние 41 разметка
  собираются байт в байт;
- отбор глазами: прямоугольный контур, одна высота карниза (иначе — в опись «ждёт» с причиной,
  как у gf#323); опись кандидатов с причиной — в низ файла;
- разметка отобранных домов: `markup/stroim/<id>.toml`, условия использования — `LICENSE.md` папки.

Требования: `openspec/specs/data/spec.md` — «Реальные коттеджи — тест», «Разметка — запись чертежа целиком».

Готово, когда:
- скрипт скачал проекты в `data/stroim/<id>/`, второй запуск ничего не скачивает (вывод команды);
- тест сборщика: разметка в метрах даёт тот же дом, что в футах; прежние 27 домов теста —
  без изменений;
- не меньше 10 российских домов размечены; `genfacade manual` собирает их, годные — в тесте,
  ошибок валидатора 0; остальные — в описи с причиной;
- картинки сверки (`tools/markup.py`) всех новых домов посмотрены глазами;
- `genfacade realtest` нынешней моделью на расширенном тесте — числа в низу файла, отдельно по
  российским домам;
