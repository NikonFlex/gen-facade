## Описание из трекера

ТЗ 7.7: совместимость с CAD. Требование `facade: CAD через экспорт` — SVG в DXF готовой библиотекой, своего конвертера нет (решение 28.09). Задачи не было (таблица требований — ❌).

Что сделать: найти готовую библиотеку SVG → DXF (ezdxf, svg2dxf, Inkscape CLI и т. п. — лицензия, живость, держит ли слои и цвета); `genfacade dxf <прогон> -o sheet.dxf`; слои по классам элементов (стены, окна, двери, отделка, отметки); кнопка «DXF» в смотрелке у листа.

Готово, когда: DXF листа простого дома открывается в свободной CAD-программе (LibreCAD или онлайн-просмотрщик), слои по классам на месте, число окон и дверей совпадает с листом; тест на чтение DXF обратно.
