## Описание из трекера

Единственный найденный источник **реальных векторных чертежей фасадов частных
домов в public domain**. Проверено лично: комплект `missouri-st-drawings.pdf`,
99 листов, страницы 31–34 это `EXTERIOR ELEVATIONS`, на листе фасада
31 595 векторных объектов, штамп `PUBLIC DOMAIN` на 97 листах из 99.

По Wayback CDX: **76 комплектов, ~2.64 ГБ**. SD2011 (20), SD2013 (20),
SD2015 (15), SD2017 (12), SD2020 (9), плюс SDE2010 (16, но там сканы).
Грубо 300–500 отдельных листов фасадов — порядок CMP.

**Почему срочно.** `solardecathlon.gov` переименован, старые пути отдают мягкий
404 (HTTP 200 с HTML главной). Живо только через Wayback, последние снапшоты —
декабрь 2024, сам Internet Archive периодически недоступен. Промедление здесь
стоит данных, а не времени.

Что сделать:
- выгрузить список всех комплектов через Wayback CDX;
- скачать через `web.archive.org/web/<ts>if_/<url>`;
- проверить каждый на векторность (сканы отбросить или пометить);
- решить с хозяином, где хранить: в git такое не положишь.

Готово, когда: архив скачан, разложен, посчитано сколько комплектов векторные
и сколько в них листов фасадов, место хранения согласовано, ссылки и метод
выгрузки записаны в `docs/datasets.md`.

## Что опровергнуто

**Оценка «300–500 листов фасадов» оказалась завышенной впятеро.**
Она строилась на предположении «2–4 листа фасадов на комплект» по индексным
страницам. Реально в среднем **2.6 листа на векторный комплект**, а суммарно
по чистым правам — **69 листов**. Это на порядок меньше 606 изображений CMP.

**«Public domain на всех комплектах» — тоже неверно.** Штамп стоит только
на 30 из 44 векторных. У 14 векторных комплектов с листами фасадов штампа нет
вообще: `appst_cd`, `scical_cd`, `swiss-drawings`, `usc_cd` (по 5 листов каждый),
`nu_cd`, `wash-state-drawings` и другие. Права по ним **под вопросом**,
использовать их без выяснения нельзя.

Обе ошибки — из оценки по одному комплекту и по индексным листам,
а не по всей выборке.

## Тупики
