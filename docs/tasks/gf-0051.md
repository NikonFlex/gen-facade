## Описание из трекера

Правило на месте модели шага 1 по `specs/generation.md` (п. 2): из текста — тип дома, этажность,
высота этажа, крыша, стиль, палитра. Описания пока на английском (хозяин 30.09).

сломанном коде. Точность на ручном тестовом наборе — этап 2 (gf#13).

## Что установлено

- `genfacade/spec/rule.py` + `config/spec.toml`: словарь английских шаблонов (целые слова,
  без регистра) → тип, этажность, высота этажа, стиль, крыша, материалы по ролям; для каждого
  поля — найденная фраза или `None` (по умолчанию).
- Набор из 14 описаний написан **до кода** (`tests/fixtures/texts/en.json`), включая пример
  из `classifier.py` GenPlan; все 14 разобраны верно (этажность, крыша, тип). 7 поломок по одной
  ловятся тестами.
- Высота этажа — три уровня 2.5 / 2.75 / 3.0 м, как `WallSizeType` GenPlan; уклон двускатной 30°,
  односкатной 15° — как `DEFAULT_ROOF_ANGLE_2/1` `[проверено: convertor.py:35-36, classifier.py]`.
- GenPlan получает текст на английском `[проверено: README, classifier.py]` — решение про язык
  совпадает с входом GenPlan.
- Решения по ходу: у многоквартирного без крыши в тексте — плоская; у коттеджа — крыша стиля;
  палитра — `id` по ролям `main/plinth/accent/trim/roof` (раскладке шага 4 так ясно, чем красить).
