## Описание из трекера

Правило на месте модели шага 1 по `specs/generation.md` (п. 2): из текста — тип дома, этажность,
высота этажа, крыша, стиль, палитра. Описания пока на английском (хозяин 30.09).
Палитры и значения по умолчанию — готовые наборы в `genfacade/config/`. `HouseSpec`
можно задать JSON без текста (условная генерация, ТЗ п. 8).

**Готово, когда:** на наборе из 10–15 английских описаний, написанных до кода, этажность и тип крыши
извлекаются верно; чего нет в тексте — берётся по умолчанию и помечается в трассе; тесты проверены на
сломанном коде. Точность на ручном тестовом наборе — этап 2 (gf#13).
