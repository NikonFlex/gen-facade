## Что установлено

- Два свеса: `Roof.overhang_m` — карнизный (за стену со скатом), `Roof.gable_overhang_m` — фронтонный (за стену без ската), None — как карнизный (старые примеры строятся как раньше); `Roofline.outline()` — контур кровли, каждая сторона вынесена на свой свес (пересечение полуплоскостей), при равных свесах — прежний `buffer(mitre)`; там, где важен только вынос (рамки вида, отсечки, `_ledge`, синтетика, поле листа), — наибольший (`reach`). 3D и IFC берут грани из `roof.faces`.
- **Разметка по чертежам** (11.11.2026, два Sonnet, растр с линейкой против `wall` вида; поле `overhang_by`): с чертежа — 56 из 59 (FreeFarmhouse 27 из 27, Solar Decathlon 19 из 22, строим.дом.рф 10 из 10), по умолчанию — sd-alabama-2017, sd-sit-2013 (свес не отделить от навесов над террасами), sd-ghent-2011 (верх стены не просмотрен).
