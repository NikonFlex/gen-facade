## Что установлено

- Формальное представление фасада в Facades-3D уже есть:
  `BuildingGrid` (сетка этажей и пролётов в метрах), `FacadeGeometry` (~25 параметров),
  `Element` (класс + axis-aligned прямоугольник), `FloorConcept`, `UpperFloorStyle` —
  `facade_semantic_map_gen_v2.py:159-238` (2026-09-25).
- `Element` структурно совпадает с аннотацией CMP: класс плюс axis-aligned прямоугольник.
- Пайплайн: mass-модель → `walls_clustering` → процедурная генерация структуры →
  растеризация в сегментацию → SD 1.4 + ControlNet-seg + LoRA `buildingface` +
  IP-Adapter → TRELLIS → 3D-меш. Модели перечислены в `src/default_configs.py:15-23`.
- Лицензия MIT, © 2026 ITMO CT Lab — проверено в файле LICENSE.
- Палитра `COLORS` (строки 26-34) совпадает с палитрой масок CMP **точно, 7 из 7
  классов** — сверено программно (2026-09-25).
- Facades-3D задействует только 7 классов из 12. `blind`, `deco`, `pillar`, `shop` —
  19 232 объекта, 37% разметки CMP — их генератор не порождает вообще.

## Что опровергнуто

- Думали, что Facades-3D делает то же, что тема диплома, и работа рискует оказаться
  пересказом. Проверили по коду: **векторного выхода нет нигде**, поиск по
  `svg|vector(iz|ise)|potrace|cairo|dxf|cad` по всему репозиторию (кроме `third_party/`)
  даёт ноль совпадений (2026-09-25).
- Думали, что текстовый промпт управляет структурой фасада. Нет: `gen_wall.py:280`
  вызывает `render_facade_segmentation(width_m, height_m, pixels_per_meter, seed)` —
  промпта там нет. Текст уходит только в диффузию и влияет на внешний вид.
