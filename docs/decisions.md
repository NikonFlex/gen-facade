## 2026-09-21 — 3D-визуализация выведена из скоупа
**Статус:** принято
**Контекст:** в ТЗ и в первом понимании задачи фигурировало натягивание фасадов
на 3D-модели домов из GenPlan.
**Решение:** 3D-генерация и интеграция в GenPlan в дипломную работу не входят.
Для демонстрации достаточно натянуть фасад на простой куб/параллелепипед.
**Причина:** Егор берёт это на себя — «добавление в GenPlan думаю я буду сам делать».
**Альтернативы:** делать 3D самому — отклонено, раздувает скоуп без научной отдачи.

## 2026-09-25 — CMP Facade принят как основной датасет
**Статус:** предложено
**Контекст:** нужно было понять, существует ли структурная разметка фасадов, —
от этого зависел выбор между путём A (генерация сразу в векторе) и путём B
(растр + векторизация).
**Решение:** взять CMP Facade основным датасетом.
**Причина:** разбор показал, что разметка — 51 769 axis-aligned прямоугольников
с классами в нормализованных координатах, то есть готовое структурное представление.
Плюс измеренная регулярность: 81.2% фасадов выровнены по этажам точнее 10% высоты окна,
CV шага между этажами 0.085. Структурный приор сильный и измеримый.
**Альтернативы:** City-Facade — облака точек, не подходит; high-res facade parsing —
только маски, не проверен. Расширение выборки другими датасетами отложено,
список кандидатов в datasets.md.
**Открыто:** 606 изображений мало; в датасете нет текстовых описаний, а по контракту
задачи вход — описание, значит описания надо генерировать из разметки самим.

## 2026-09-25 — не писать своё там, где есть лабораторное
**Статус:** принято
**Контекст:** разбор организации CTLab-ITMO показал шесть репозиториев по теме
(см. [lab-repos.md](lab-repos.md)).
**Решение:** растровую генерацию брать из Facades-3D, векторизацию — из EvoVec (VGLib)
и LIVBOC, каптионинг описаний — из Text2SVG. Своё писать только там, где готового нет.
**Причина:** правило 1; плюс переиспользование лабораторного кода — это то, чего ждёт Егор
(«будем вместе +- работать»), и оно ускоряет путь к статье.
**Альтернативы:** поднимать диффузию и векторизатор самому — отклонено, это месяцы работы
без научной отдачи.
