# Метрики и проверки корректности

Обновлено: 2026-09-25

ТЗ требует оценку по пяти группам метрик и отдельно — автоматические проверки
геометрической корректности. Это один из немногих пунктов ТЗ, сформулированных
конкретно, поэтому на защите спросят обязательно.

Пока ничего не выбрано — файл задаёт рамку, которую надо наполнить.

## Пять групп из ТЗ

### 1. Визуальное сходство
Насколько сгенерированный фасад похож на настоящие.
Кандидаты: FID, KID, LPIPS по растеризованному SVG; попиксельный MSE/IoU при сравнении
векторизации с исходным растром. Не выбрано.

### 2. Корректность геометрии
Нет самопересечений, замкнутые контуры, элементы не выходят за границы фасада,
не перекрываются недопустимым образом, линии параллельны/перпендикулярны где должны.
Считается прямо по SVG, без обучения. Не выбрано.

### 3. Корректность структуры
Самое важное для нашей гипотезы вклада (см. [methods.md](methods.md)):
регулярность сетки этажей, выравнивание элементов по вертикальным осям, одинаковость
размеров однотипных элементов, соответствие числа этажей и элементов заданному условию.
**Готовых метрик, скорее всего, нет — возможно, их придётся предложить самим.**
Это само по себе может быть частью научного вклада.

### 4. Разнообразие
Чтобы модель не выдавала один и тот же фасад. Кандидаты: внутренняя вариативность
выборки, recall/coverage в дополнение к FID. Не выбрано.

### 5. Доля валидных векторных документов
Процент выходов, которые парсятся как корректный SVG и открываются в целевом
редакторе/CAD. Самая простая в реализации метрика, стоит сделать первой —
она же служит smoke-тестом пайплайна.

## Автоматические проверки геометрической корректности

Отдельный пункт ТЗ. По сути — валидатор, который принимает SVG и выдаёт список
нарушений. Черновой набор правил:

- [ ] SVG парсится, все элементы имеют валидные координаты
- [ ] контуры замкнуты, нет самопересечений
- [ ] все элементы внутри габаритов фасада
- [ ] окна/двери не пересекаются друг с другом
- [ ] элементы одного класса на одном этаже имеют одинаковый размер (с допуском)
- [ ] элементы выровнены по вертикальным осям (с допуском)
- [ ] шаг между этажами постоянен (с допуском)
- [ ] число этажей и элементов соответствует условию генерации

Допуски надо будет обосновать — либо из разметки реальных фасадов, либо экспертно.
