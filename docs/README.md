## Рабочие заметки по задачам

Здесь — тематическая база знаний. Рабочие заметки по конкретным задачам живут
отдельно, в [tasks/](tasks/): по файлу на задачу GitHub, низ файла не трогается
синхронизацией. Индекс — [tasks/INDEX.md](tasks/INDEX.md), обзор застрявшего —
`python3 tools/backlog.py review`. Правила — раздел «Задачи» в [../AGENTS.md](../AGENTS.md).

Искать по задачам — `grep -ri <слово> docs/tasks/`.

Граница с [decisions.md](decisions.md): в низу задачи — ход конкретной работы,
в журнале решений — выбор, который пережил задачу и который будут спрашивать
на защите («почему так, а не иначе»). Если решение касается только одной задачи,
ему хватит её файла.

## Как помечать факты

Каждое содержательное утверждение сопровождается пометкой достоверности:

- `[проверено: <чем>]` — открыли первоисточник сами. Указывать, чем именно:
  страница датасета, полный текст статьи, код репозитория, свой эксперимент.
- `[из абстракта]` — взято из аннотации, README или чужого пересказа. Для диплома
  недостаточно, нужно дочитать первоисточник.
- `[не проверено]` — знаем со слов или предполагаем.

Без пометки утверждение считается непроверенным и в текст диплома не идёт.
