# Входящие документы

Документы от научных руководителей и других людей — **как получены**.
Это не требования: канон — только то, что перенесено в [specs/](../../specs/README.md).
Порядок работы — [docs/SPEC-DRIVEN.md](../SPEC-DRIVEN.md).

- Файл после приёма **не правится никогда**. Новая редакция — новый файл,
  старая запись в индексе получает статус `superseded`.
- Каждый файл записан в [index.yaml](index.yaml) с `sha256`; статус меняется
  по мере разбора: `incoming → reviewed → distilled | rejected | superseded`.
- Обычный поиск (`rg`) эту папку пропускает (`.rgignore`), чтобы входящие
  не читались как требования. Искать явно: `rg --no-ignore <слово> docs/incoming/`.
