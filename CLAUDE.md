# Только для Claude Code

Общие правила — `AGENTS.md` выше (импорт), одинаковые для Claude Code, Codex и Cursor. Здесь —
то, что есть только у Claude Code. Рабочий язык — русский, терминология английская.

- **Навыки**: в новом чате — `/catchup`; путаница в контексте — `/contradictions`; задачи —
  `/task`; приёмка сделанного — `/accept`; журнал — `/journal`; доля задач с первого промпта —
  `/fpsr`; переписка из Telegram — `/inbox`; сообщение научрукам — `/to-supervisors`, только
  когда хозяин попросил.
- **Правила по темам** подгружаются из `.claude/rules/` по путям файлов — это копии
  `docs/agents/` (`tools/agent_rules.py`). Писать код или спеку, не открыв файл через
  Read/Edit/Write, — значит работать без этих правил.
- **Хуки** (`.claude/settings.json`): перед каждым сообщением — напоминание «сначала задача» и
  заполненность контекста; перед Bash и Read — сторож `.agents/guards/guard.py`; при старте —
  `tools/install_hooks.sh` (git-хуки, `git ticket`); после сжатия — над какой задачей работали;
  уведомления в Telegram — `tools/tg_ping.py`. `.env` не читается.

## Субагенты

Независимые куски (несколько репозиториев, статей, датасетов, конфигураций эксперимента) —
параллельно инструментом `Agent`, несколько вызовов в одном сообщении. Не параллелить, когда
куски зависят друг от друга, когда вывод критичен для темы — за него отвечать на защите — и
когда субагенты писали бы в одни файлы: пусть возвращают находки, в `docs/` пишет основная сессия.

Модель субагента (`model` у `Agent`) выбирается по работе, Opus — дорого (хозяин 01.11):

- **`haiku`** — механическое без решений: поиск по файлам, прогон тестов или скрипта и пересказ
  результата, числа из логов и артефактов в таблицу, картинки листов, проверка ссылок и лицензий.
- **`sonnet`** — код по ясной постановке: задача с «Готово, когда», известными файлами и
  описанным решением; тесты, датчики, конвертеры данных, разбор конфликтов слияния.
- **Opus — основная сессия**: постановка и бриф субагенту, спеки, архитектура, разбор
  результатов, ревью диффа субагента перед PR. Субагент на Opus — только когда сначала надо
  решить, как делать, и ошибка дорогая (формат токенов, страж).

Долгие команды субагент запускает одним вызовом с большим timeout и не опрашивает: каждый
опрос заново шлёт весь его контекст. Одновременно — не больше трёх субагентов, пишущих код:
иначе хуки коммитов идут часами. В ответе назвать, какой модели что отдано. Что вернул
субагент — пересказ: ключевое перед `[проверено]` перепроверить.

## Контекст

Чем больше занято контекста, тем хуже держатся правила. Выше порога (окно и пороги —
`.claude/context.json`) хук пишет «Контекст: N% … порог «…»»; `/compact` он не запускает —
Claude предлагает, одной строкой, первой в ответе:

**new_chat** — на границе задачи предложить новый чат, посреди задачи не отвлекать;
**compact** — перед крупным шагом предложить `/compact <на чём сосредоточиться>` или новый
чат; **urgent** — предложить сейчас. Перед этим обновить «Чем возобновлять» в задаче.
